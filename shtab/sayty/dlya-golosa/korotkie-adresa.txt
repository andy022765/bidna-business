# Короткие адреса лендингов — строки для _redirects основного сайта.
# Готовил ШТАБ 23.09, НЕ выкачено: ждёт слова Андрея по формулировкам.
#
# Зачем: неудобно диктовать businessinteldna.com/visibility. Слэш на конце уже не нужен —
# /vera, /visibility, /call-audit, /diagnostic отдают 301 сами (проверено живьём).
# Ниже добавляются слова, которые понятнее по-русски, и русские адреса без /ru.
#
# ВАЖНО про порядок: Netlify берёт ПЕРВОЕ подходящее правило. Эти строки должны идти
# ДО общих правил, иначе их перехватит что-то другое.

# — английские короткие —
/geo         /visibility/     301!
/audit       /call-audit/     301!
/dna         /diagnostic/     301!

# — русские: одна ссылка сразу на русскую версию, без /ru —
/vidimost    /visibility/ru/  301!
/priemka     /call-audit/ru/  301!
/vera-ru     /vera/ru/        301!
/diagnostika /diagnostic/ru/  301!

# Восклицательный знак в 301! — чтобы правило работало даже если по этому адресу
# однажды появится настоящая страница. Иначе файл будет молча перестать работать.
