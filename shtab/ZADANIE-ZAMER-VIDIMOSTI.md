# Задание окну на Маке: нулевой замер видимости (второй фронт, zamer-v5)

Запускать на Маке (ключи в `~/.bidna-smotritel.env`). Цена ≈ $9.74, 252 ответа, ~1 час. Лимит воркспейса Smotritel на октябрь — $50 (проверено 01.10).
Вопросы заморожены до 22.12 (хэш в `zamer-v5/ZAMOROZHENO.md`) — не менять. Слот `den` рассчитан на 11:00–16:00 LA, после 16:00 нужен `--vne-okna`.

## Текст для вставки в окно Мака
Нулевой замер видимости, zamer-v5. Из папки Drive `Pivot/agenty/smotritel`:
1. Сначала только оценка, ничего не тратит:
   `set -a; source ~/.bidna-smotritel.env; set +a; /Library/Frameworks/Python.framework/Versions/3.14/bin/python3 progon/progon.py --slot den --nabor-zamera zamer-v5 --povtorov 7 --rezhimy poisk --vne-okna --plan`
   Если оценка больше $12 или ошибка — остановись и скажи Андрею.
2. Если ≈ $9.74 — тот же запуск без `--plan`, через `caffeinate -i`, одним слотом подряд (разносить по дням нельзя).
3. Упавшие ответы добрать повторным запуском той же команды (готовые не перезаписываются).
4. Результат: `python3 kriteriy-v2.py zamer-v5` — показать Андрею итог («4 из 7» по каждому вопросу). При неполном замере вывод не делать.
5. Записать в `shtab/DOSKA.md` одну строку (дата, цена, итог) и вычеркнуть пункт в `shtab/SEGODNYA.md`.
Не запускать после 22:00 LA и не запускать второй раз за день.
