## Как синхронизируется
- **Drive → GitHub:** `bash shtab/github/zerkalo.sh` на Маке (rsync по списку исключений → commit → push в main).
  Запускать перед облачной сессией, чтобы облако видело свежее.
- **GitHub → Drive:** облачная сессия коммитит в `main` или ветку `claude/*`; главный агент на Маке делает `git pull`
  в зеркале, смотрит diff и переносит в Drive только проверенные файлы. Состояние чужих систем (сайты, Netlify) — не переносится.
- Выкладки сайтов, Chrome, Twilio, Netlify, Google Drive — только с Мака; облачная сессия пишет тексты, код, разборы.
