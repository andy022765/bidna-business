## Как загружали (на будущее)
1. Файлы положены в Google Drive, папка «Загрузить в Meta» в корне «Моего диска» (копией `cp -X` — обычный `cp`
   переносит чужой item-id в атрибутах, ID берётся из `xattr -p 'com.google.drivefs.item-id#S'`).
2. Андрей 28.09: «Да, открой сам» → доступ «Anyone with the link, Viewer» открыт через Chrome, после загрузки закрыт
   обратно (Restricted), ссылки отдают 302 на вход — проверено.
3. Ролики: `https://drive.usercontent.google.com/download?id=<ID>&export=download` — Meta берёт.
4. Картинки: этот адрес Meta НЕ берёт («Image Wasn't Downloaded… robots.txt» — у drive.usercontent.google.com
   `Disallow: /`). Берёт `https://lh3.googleusercontent.com/d/<ID>=s0` — отдаёт исходный PNG байт в байт.
5. Вечерняя папка на сайте для таких загрузок больше не обязательна — этот путь работает без выкатки.

Исходники роликов: `media/reklama-meta/` (прежние версии — `_v2/`, `_v1/`), сборка — `targetolog/sborka/rolik.py`.
