# Охват движков у потребителей США: ChatGPT 44%, Gemini 24%, Copilot 17%, Claude 6%

По Pew (февраль 2026) ChatGPT пользуются 44% взрослых (год назад 34%), Gemini 24%, Copilot 17%, Meta AI 14%, Grok 8%, Claude 6%. Perplexity в перечне Pew не выделен. Для замера это порядок важности: ChatGPT и Google-экосистема (Gemini, AI Overviews, AI Mode) покрывают основную массу, Claude — нишевый. У Смотрителя Gemini по официальному API мерить нельзя (условия Google), а AI Overviews/AI Mode — только через сторонний сборщик; это самая большая дыра замера по охвату, и её надо называть клиенту. Вес движков в отчёте клиенту стоит показывать с этими долями, а не «4 движка поровну».
