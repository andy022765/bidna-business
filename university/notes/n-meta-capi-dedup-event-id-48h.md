# Одинаковые события из пикселя и CAPI Meta склеивает по event_name и event_id в окне 48 часов; при разнице меньше 5 минут берёт браузерное

Документация параметров: event_id — любая уникальная строка рекламодателя; вместе с event_name она служит для дедупликации событий, пришедших и из браузера (у пикселя это eventID, четвёртый аргумент fbq('track', …)), и с сервера. Если совпадение найдено для событий, отправленных в пределах 48 часов, учитывается первое; если серверное и браузерное пришли почти одновременно (в пределах 5 минут), Meta предпочитает браузерное. Для покупки удобный event_id — номер заказа или транзакции; для событий без своего номера — случайное значение, одинаковое в браузере и на сервере. Без общего event_id одна покупка посчитается дважды.
