# Самозанятых иммигрантов 3,5 млн, а владельцев инкорпорированных фирм среди них только 1,3 млн (37%)

IRI разделяет «самозанятых» и «владельцев»: из 3,5 млн самозанятых иммигрантов 1,3 млн владеют инкорпорированной фирмой. В стройке 649 тыс. самозанятых иммигрантов, из них 194 тыс. — владельцы фирм; остальные — поденщики, фрилансеры, неверно оформленные работники. Для оценки рынка это коэффициент ~0,37: наш покупатель — владелец фирмы с потоком заявок, а не одиночка-субподрядчик.
