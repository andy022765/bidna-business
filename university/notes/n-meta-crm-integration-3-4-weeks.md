# До полного эффекта CRM-интеграции Meta закладывает 3–4 недели, из них 2–4 недели — обучение на воронке после проверки данных

План проекта из той же документации: загрузка лидов в CRM (предусловие), набор данных (меньше дня), реализация интеграции (через партнёра — меньше дня, своя — 3–4 недели), проверка данных Meta (1–2 дня), настройка стадий воронки (меньше дня), обучение на воронке (2–4 недели). Итоговая оценка — около 3–4 недель; кампании в период обучения запускать можно, но без полного эффекта. Среди партнёров для такой интеграции документация называет Zapier.
