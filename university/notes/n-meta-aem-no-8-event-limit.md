# Aggregated Event Measurement больше не требует ранжировать 8 событий на домен и верифицировать домен ради настройки событий; вкладку AEM из Events Manager убрали

Справка «About Meta's Aggregated Event Measurement» (721422165168355, извлечено 27.09.2026) перечисляет изменения для веб-кампаний: не нужно выбирать 8 приоритетных событий на домен и включать value sets для оптимизации на ценность; вкладка AEM в Events Manager удалена; верификация домена для настройки событий не требуется (но может понадобиться по другим причинам); домен конверсии при создании кампании выбирать не нужно. Действий от рекламодателя не требуется. Оговорка: события через Conversions API тоже могут обрабатываться в пределах ограничений AEM. Советы 2021–2024 годов «сначала верифицируй домен и расставь 8 событий» устарели.
