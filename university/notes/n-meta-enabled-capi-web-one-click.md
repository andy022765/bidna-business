# Meta-enabled Conversions API — бесплатный вариант «в один клик» только для сайта: он дублирует на сервер события и параметры пикселя и сам их дедуплицирует

Справка «Compare Conversions API setup options» (433493041367251, извлечено 27.09.2026) сравнивает три пути. Meta-enabled CAPI: бесплатно, один клик, нужен только пиксель, источник — только web; события и параметры берутся из пикселя и автоматически дедуплицируются. Прямая интеграция: разработчик, 2–4 недели для новой (1–2 недели, если веб уже подключён), источники — web, app, offline, CRM, business messaging, события и параметры настраиваются. Партнёры: цена и сроки — у партнёра. Значит, серверную копию событий лендинга можно получить без кода, но добавить в неё то, чего нет в браузере (итог звонка, оплату из вебхука), так нельзя.
