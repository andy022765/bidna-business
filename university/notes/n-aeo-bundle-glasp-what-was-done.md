# В единственном кейсе с контролем работы были простыми: один адрес на страницу, новые страницы по несуществующим адресам, которые запрашивали боты, заголовки-вопросы и ответ в первых 2–3 предложениях

Набор Glasp: склейка дублей URL в один канонический адрес; «спрос из 404» — адреса, которые запрашивали ИИ-боты и которых не было, превращали в новые страницы; заголовки переписали в форме вопроса, а вводный абзац — в самостоятельный ответ из 2–3 предложений; страницы с трафиком из Google не трогали. Эффект оценён только для набора целиком. Для нас полезны два приёма: смотреть в логах, какие несуществующие адреса ищут боты, и начинать страницу с прямого ответа. Сайт контентный, перенос на местный бизнес не проверен.
