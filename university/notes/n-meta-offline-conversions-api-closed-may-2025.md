# Offline Conversions API закрыт в мае 2025 года: офлайн-события отправляются только через Conversions API в наборы данных

Справка по CAPI содержит примечание: Offline Conversions API прекращает работу в мае 2025 года, загружать события в offline event sets через него больше нельзя, интеграции переводятся на Conversions API и наборы данных (datasets). Советы «грузите звонки через Offline Conversions API» устарели. Остаётся ручная загрузка CSV в Events Manager (статья 155437961572700, в очереди): загруженные строки потом нельзя удалить или исправить.
