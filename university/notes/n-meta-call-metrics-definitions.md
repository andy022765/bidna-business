# Метрики рекламы со звонком: calls placed — звонки, начатые из объявления; 20-/60-second calls — соединения не короче 20/60 секунд; callback requests — просьбы перезвонить

Статья 237108475737601 (извлечено 27.09.2026): calls placed — сколько раз из объявления позвонили в бизнес; 20-second calls и 60-second calls — сколько звонков закончились успешным соединением не короче 20 или 60 секунд; callback requests submitted — сколько людей через кнопку «Отправить сообщение» попросили перезвонить; ещё есть estimated call confirmation clicks — оценка нажатий подтверждения вызова. Колонки включаются в Ads Manager: Columns → Customize columns → Engagement → Calling. Метрики доступны глобально, кроме кампаний, созданных до 20.06.2025 вне США, Австралии, Бразилии, Канады, Мексики и Израиля. Их же показывает Call insights в Meta Business Suite.
