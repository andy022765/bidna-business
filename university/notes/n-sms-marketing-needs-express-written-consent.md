# Маркетинговые SMS по правилам операторов (CTIA) идут только после opt-in, для маркетинга — с письменного согласия; купленные и чужие списки запрещены

CTIA Messaging Principles (май 2023): отправитель должен получить согласие потребителя на сообщения, для маркетинговых — express written consent, и дать возможность отозвать согласие; сообщения шлются только после opt-in; согласие документируется (время, способ, текст призыва, кампания, IP, номер). Opt-in-списки нельзя продавать, сдавать и передавать. Нежелательные сообщения — включая массовые непрошенные — операторы блокируют. Это правила отрасли поверх TCPA, но через регистрацию 10DLC они исполняются технически.

Значит, холодные SMS владельцам как канал привлечения для нас закрыты. SMS остаются только для тех, кто сам дал согласие: например, клиент клиента, оставивший номер Вере с согласием (Доводчик), — и это отдельная юридическая работа (см. contr-006).
