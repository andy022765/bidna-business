# OpenAI prices gpt-realtime-2.1 audio at $32/$64 per million tokens, chat-latest at $5/$30, and web search at $10 per 1,000 calls plus content tokens

Прайс OpenAI на 24.09.2026: chat-latest (модель ChatGPT) $5 вход / $30 выход за миллион; gpt-6-sol $2/$10. Голос: gpt-realtime-2.1 — аудио $32/$64 (кэш $0.40), gpt-realtime-2.1-mini — $10/$20, gpt-live-1 — $0.05/мин плюс модель. Веб-поиск $10 за 1 000 вызовов плюс токены найденного контента по цене модели. Для замера вызов chat-latest с поиском ≈ $0.08 (наша оценка; память 15.09 давала ~$0.027) — меньше цента-десяти на вопрос.
