# Anthropic's commercial terms let API customers own outputs and forbid Anthropic from training on customer content

Commercial Terms (с 17.06.2025): клиент может строить на API продукты для своих пользователей, владеет выходами, Anthropic не обучает модели на данных клиента из сервисов. Запреты — строить конкурирующий продукт, обучать конкурирующие модели, перепродавать сервисы без одобрения. Хранение и анализ ответов Claude для замера видимости этими условиями не запрещены. Уверенность M: Usage Policy отдельно не прочитана (в очереди), а исполнитель анализа — модель Anthropic.
