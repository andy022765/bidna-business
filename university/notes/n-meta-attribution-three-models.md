# В Meta три модели атрибуции — стандартная, инкрементальная и пользовательская; сравнивать результаты групп с разными моделями нельзя

Справка «About attribution models and attribution settings» (460276478298895, извлечено 27.09.2026): модель выбирается на уровне группы. Стандартная засчитывает конверсии в выбранном окне по показу, клику и/или вовлечению; инкрементальная оптимизирует и отчитывается по конверсиям, которые, по модели Meta, вызвала реклама; пользовательская принимает данные атрибуции из внешней аналитики. Meta предупреждает: результаты групп с разными моделями в общей таблице несравнимы, сравнивать нужно через Compare attribution settings или во внешнем инструменте. Настройки окон есть только у стандартной модели.
