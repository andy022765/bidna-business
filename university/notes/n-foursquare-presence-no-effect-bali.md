# Присутствие в Foursquare не повышало шанс рекомендации ИИ в аудите Бали

Аудит частично строился для проверки гипотезы, что поставщики точек интереса (Foursquare) определяют местные ответы ИИ. Результат нулевой: OR 0,84 на входе, незначимо; внутри Foursquare ни качество данных, ни число советов, ни популярность не значимы. Проверка сделана через API с поиском, на рынке Бали и на английском. Это противоречит распространённому в индустрии тезису о Foursquare как главном источнике ChatGPT по местным запросам (см. contr-012).
