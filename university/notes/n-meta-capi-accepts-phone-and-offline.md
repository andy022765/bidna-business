# Conversions API принимает события сайта, магазина, почты, чатов, телефона, приложения и офлайна — одним API в один набор данных

По справке CAPI принимает события из разных источников: сайт, магазин, почта, чаты, телефон, мобильное приложение и офлайн; данные могут идти с сервера, платформы сайта, приложения или CRM. В параметрах серверного события этому соответствует поле action_source (email, website, app, phone_call, chat, physical_store, system_generated, business_messaging, other). Офлайн-события помогают мерить результаты в точках продаж, строить по ним аудитории и lookalike, запускать lift-исследования. Утверждение брифа-bidna §9 «CAPI принимает офлайн-события по телефонным звонкам из CRM» этим подтверждается.
