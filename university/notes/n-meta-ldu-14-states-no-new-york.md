# Флаг Limited Data Use работает для жителей 14 штатов — CA, CO, CT, DE, FL, MD, MN, MT, NE, NH, NJ, OR, RI, TX; Нью-Йорка в списке нет

Справка «About Limited Data Use» (1151133471911882, извлечено 27.09.2026): флаг доступен в пикселе, Conversions API, App Events API, SDK и Offline Conversions API для 14 штатов — Калифорния, Колорадо, Коннектикут, Делавэр, Флорида, Мэриленд, Миннесота, Монтана, Небраска, Нью-Гэмпшир, Нью-Джерси, Орегон, Род-Айленд, Техас. Для загрузки списков клиентов (customer list) — только Калифорния. Даты вступления по штатам — в документации Data Processing Options (в очереди). Нью-Йорка в списке нет, причину справка не объясняет; для половины нашей географии флаг просто не действует.
