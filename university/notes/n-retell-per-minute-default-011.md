# Retell's default voice-agent configuration costs about $0.11 per minute, and $0.135 with ElevenLabs voices

Прайс Retell (витрина): pay-as-you-go $0.07–0.31/мин по конфигурации. Калькулятор по умолчанию $0.11: голосовая инфраструктура $0.055, LLM $0.04, голос $0.015; голоса ElevenLabs — $0.040 вместо $0.015, то есть около $0.135/мин. Уверенность M: витрина вендора, реальная цена зависит от LLM и длины промпта. Экономии относительно нашего стека ($0.10–0.11) нет.
