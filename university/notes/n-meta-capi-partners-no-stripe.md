# Среди способов подключить CAPI в справке Meta нет Stripe: названы коммерческие платформы (Shopify, WooCommerce, Wix, BigCommerce), теги (Adobe, Google Tag Manager, Tealium), мессенджеры и CRM

В статье о вариантах подключения Conversions API партнёрские интеграции перечислены группами: коммерческие платформы — Shopify, WooCommerce, Wix, BigCommerce («несколько кликов и бесплатно»); платформы сайтов и тегов — Adobe, Google Tag Manager, Tealium и другие; партнёры по переписке; партнёры CRM. Stripe не назван. В отдельном списке партнёров для веб-событий (260370078559247, прочитан, в очереди) Stripe тоже нет, зато есть Zapier, LeadsBridge и Make (Integromat); у Zapier есть шаблон «Stripe → Facebook Conversions» (витрина, не проверено). Вывод со средней уверенностью: официальной связки Stripe → Meta нет, Purchase из Stripe отправляем сами с сервера по вебхуку оплаты.
