# A customer testimonial about a key result is read as typical, so atypical results require disclosure of generally expected performance

16 CFR 255.2(a): отзывы потребителей не являются доказательством; рекламодатель должен иметь обоснование утверждений, переданных через отзыв, как если бы сказал их сам. 255.2(b): опыт клиента по ключевому свойству читается как то, чего обычно достигают все; если нет обоснования типичности, нужно ясно раскрыть обычно ожидаемый результат. Для кейса Юли или любого будущего кейса Веры с цифрами: рядом нужен типичный результат по нашим клиентам или отказ от цифры.
