# Если цель эффективности — «максимум звонков», а аудитория только в США, колонка «Результаты» по умолчанию показывает звонки 20+ секунд

Примечание в статье 237108475737601: при цели «maximize number of calls» и таргетинге только на США метрика 20-second calls автоматически становится метрикой по умолчанию в колонке Results (пресет Performance). Отчёт в США показывает 20+, а оптимизация в целях Traffic/Engagement/Leads/Sales идёт на 60+. Для кампании на NY+LA «результат» в отчёте — звонок 20+ секунд, цена результата — цена такого звонка. Звонки 60+ добавляются отдельной колонкой.
