# ElevenLabs offers HIPAA BAAs only on its custom-priced Enterprise plan

На странице тарифов ElevenAgents пункт «BAAs for HIPAA customers» есть только в Enterprise (цена по договорённости) вместе с повышенной одновременностью и индивидуальными условиями DPA/SLA. Это подтверждает c-0021 (по условиям использования, проверенным 17.09): PHI без BAA передавать нельзя, BAA — только Enterprise. Стоимость Enterprise для одного клиента неизвестна; без неё экономику Веры для страховых клиник посчитать нельзя.
