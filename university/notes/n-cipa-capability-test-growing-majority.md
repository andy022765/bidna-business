# A growing number of California federal courts apply the capability test to AI and call-analytics vendors

Суд в ConverseNow ссылается на ряд решений 2023–2025 годов, где вендоры признаны третьими сторонами: Javier v. Assurance IQ, Gladstone v. Amazon Web Services (Amazon Connect в колл-центре Capital One), Yockey v. Salesforce (обучение ИИ на чатах), Turner v. Nuance (голосовые отпечатки), Tate v. VITAS (анализ звонков). Есть и противоположная линия (Graham v. Noom, дела о чатах). Тренд для голосовых ИИ неблагоприятен для вендоров. Уверенность M: это ранние стадии, решений по существу почти нет.
