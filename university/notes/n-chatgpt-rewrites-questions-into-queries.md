# ChatGPT сокращает длинный вопрос до короткого поискового запроса перед поиском

Seer объясняет неполное совпадение с Bing тем, что длинный вопрос («какие лучшие автокредиторы для людей с плохой кредитной историей?») ChatGPT переписывает в короткий запрос («best auto loan lenders bad credit»). Google описывает похожий механизм для AI Mode как веер подзапросов. Для наших вопросов «ниша + город» это значит, что страница клиента должна содержать короткие формулировки услуги и города словами, а не только развернутые ответы. Уверенность низкая: это вывод из данных Seer, а не документация OpenAI (справка OpenAI о поиске при загрузке вернула 403).
