# По руководству FTC слова «Money Back Guarantee» и «Satisfaction Guarantee» допустимы, только если продавец возвращает полную цену по требованию покупателя

16 CFR §239.3(a): продавец должен использовать термины «Satisfaction Guarantee», «Money Back Guarantee», «Free Trial Offer» и подобные только если возвращает полную цену рекламируемого продукта по запросу покупателя. По §239.1 этот раздел применяется к рекламе любой гарантии, не только потребительских товаров, а FTC может преследовать по разделу 5 любое искажение условий гарантии.

Наши возвраты условные: по Видимости — если за квартал по согласованному списку не назвали ни разу; по Вере — плата за запуск, если ошибка повторилась после двух исправлений в первые 14 дней, абонентка не возвращается. Называть их «гарантия возврата денег» в английской версии нельзя; по-русски тоже честнее «условие возврата».
