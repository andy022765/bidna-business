# Когда аудитория расширяется продуктами Advantage+, оценка размера аудитории в Ads Manager не отражает реального охвата

В примечаниях статьи 128066880933676 Meta пишет: при расширении аудитории через продукты Advantage+ оценка размера аудитории не отражает общего числа аккаунтов, подходящих под критерии. Поэтому число «потенциальный охват» в плане — ориентир для заданных условий, а не для реальной доставки. Для медиаплана это значит: размер русскоязычной аудитории NY+LA в оценке Meta не доказывает, сколько людей увидит рекламу, и сравнивать планы по этому числу нельзя. Точнее смотреть фактический охват и частоту после запуска.
