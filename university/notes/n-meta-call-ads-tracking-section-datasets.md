# К рекламе со звонком можно подключить набор данных: в разделе Tracking есть события CRM, сайта и приложения, а окно атрибуции выбирается на уровне группы

Последний шаг инструкции по созданию рекламы со звонком (604687010451937): в разделе Tracking объявления кнопка Set up подключает CRM events, website events и app events из наборов данных. Обзорная статья 378168646496279 добавляет, что окно атрибуции для рекламы со звонком выбирается на уровне группы. Значит, когда появится набор данных (пиксель и CAPI), его можно привязать и к рекламе со звонком, чтобы видеть в отчёте, например, Purchase после звонка. Меняет ли это оптимизацию (по справке она остаётся на 60-секундных звонках), статья не говорит; окно по умолчанию для звонков тоже не названо.
