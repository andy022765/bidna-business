# С 31 марта 2025 года в Ads Manager нельзя исключать аудиторию по детальному таргетингу; остались исключения custom audiences и настройки аккаунта

Справка Meta (458835214668072): исключения по детальному таргетингу убраны 31.03.2025 в Ads Manager и 10.06.2025 при продвижении постов. В новых группах их нет. Скопировать группу с исключениями, использовать сохранённую аудиторию с ними или черновик можно только после их удаления. Альтернативы, которые оставлены: исключение custom audiences и audience controls в настройках аккаунта (ограничения по бренд-защите и занятости, только выборочные опции). Для нас: «исключить нерусскоязычных» или «исключить наёмных сотрудников» интересами невозможно. Язык задаётся control'ом, а своих (например, клиентов) можно исключать только custom audience.
