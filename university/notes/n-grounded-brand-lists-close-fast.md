# С веб-поиском список названных компаний короткий и закрывается к 10–15 запускам, без поиска новые имена появляются и на 15-м

Żatuchin (2026) задал 50 покупательских вопросов по 15 раз шести движкам. Пять движков без поиска к 15-му запуску всё ещё добавляли новые организации в 86–92% ячеек, их репертуар 15–31 организация. Единственный движок с поиском (Perplexity sonar) называл медиану 8 организаций и к 15-му запуску видел весь свой набор. Один запуск показывает 62–77% набора из пяти запусков. Для замера: режим с поиском можно «добрать» за 10–15 повторов, режим без поиска остаётся открытым, и одиночное упоминание там мало что значит.
