# FTC в мае 2026 наказал маркетинговые фирмы за ложное описание «ИИ-сервиса» для малого бизнеса

Cox Media Group и две маркетинговые фирмы продавали малому бизнесу «Active Listening» — якобы ИИ-сервис, который слушает разговоры через умные устройства и показывает рекламу людям в нужном районе. По жалобам FTC ничего этого не было: продавались перепроданные с большой наценкой email-списки брокеров, геотаргетинг не соблюдался. Итог — $930 000 на компенсации клиентам и запрет искажать «качества и функции» рекламных и маркетинговых услуг, включая возможности геотаргетинга. Это ближайший к GEO прецедент: маркетинговая услуга «на ИИ» для малого бизнеса с локальной привязкой. Для Видимости следствие прямое: описание замера («что ИИ отвечает про вас в вашем городе») должно быть буквально верным — API с городом, а не то, что видит человек в приложении; AI Overviews — через сторонний сборщик; Gemini — не меряем.
