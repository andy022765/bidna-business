# Twilio signs a HIPAA Business Associate Addendum only for customers on its Security or Enterprise Edition

Страница Twilio о HIPAA: клиенты под HIPAA, передающие защищённые медицинские данные через Twilio, обязаны подписать BAA, и подписать его можно только имея Security Edition или Enterprise Edition. Это уточняет наш документ KLINIKI-I-HIPAA.md, где стояло «да, на отдельных условиях». Вместе с ElevenLabs (BAA только Enterprise) это делает Веру для клиник со страховыми заявками отдельным, дорогим продуктом.
