# California Penal Code §632 forbids recording a confidential phone call without the consent of all parties

§632(a) запрещает умышленно, без согласия всех сторон, записывать или прослушивать конфиденциальный разговор с помощью устройства, в том числе по телефону. Уголовная санкция — до $2 500 за нарушение. Конфиденциальным разговор считается, если у стороны есть разумное ожидание, что его не записывают; объявление о записи это ожидание снимает. «Лицо» включает LLC. Для Дежурного, который расшифровывает каждый звонок, объявление о записи в начале — основа законности в Калифорнии и других штатах с согласием всех сторон.
