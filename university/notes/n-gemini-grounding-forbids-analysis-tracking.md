# Gemini API terms forbid analyzing, storing or tracking Grounded Results, so Gemini with Google Search cannot be used for AI-visibility monitoring

Условия Gemini API (действуют с 23.03.2026, страница обновлена 28.04.2026): Grounding with Google Search используется только в своём приложении и показывается только спросившему; запрещено кэшировать, анализировать, обучаться, извлекать ссылки, копировать, хранить и отслеживать Grounded Results, кроме узких исключений (история чата пользователя, оценка отображения в своём приложении). Grounding with Google Maps ограничен так же. Наш вывод 14.09 подтверждён: Gemini с поиском для Смотрителя не используем.
