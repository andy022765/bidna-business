# По справке Meta 2026 года цель «квалифицированные лиды» работает и с формами на сайте, и с инстант-формами

В той же статье: «this performance goal can be used with both website forms and instant forms», и приводится отдельный эксперимент для форм на сайте. Документация для разработчиков по CRM-интеграции говорит обратное: цель Conversion Leads «currently only compatible» с инстант-формами. Расхождение — contr-112. Справка свежее (упоминает апрель и август 2026), поэтому рабочее допущение — формы на сайте поддерживаются, но проверять в Ads Manager при сборке.
