# Если в объявлении есть сгенерированный ИИ фотореалистичный человек, метка «AI info» стоит рядом с «Sponsored» и видна без нажатия

Пост Meta: «When these tools result in the inclusion of an AI-generated photorealistic human, the label will appear next to the Sponsored label (not behind the three-dot menu)». Правило описано для собственных генеративных инструментов Meta. Для людей из сторонних генераторов место метки в посте не уточнено: сказано только, что распознанная реклама получает «AI info» в «Об этой рекламе». Для нас: реалистичный ИИ-«владелец» или ИИ-«клиент» в кадре почти наверняка получит метку и одновременно создаст риск обманного отзыва по FTC (c-0609).
