# Медианный заработок иммигранта — владельца бизнеса — $50 тыс. в год

IRI по ACS 2023: медиана заработка иммигранта-владельца $50 000, у рождённых в США — $60 000, у иммигранта-работника — $40 000. Типичный иммигрантский бизнес — микро. Для цены: запуск $1000 + $199/мес — это 2,4% медианного годового заработка владельца только за абонемент, заметная сумма. Покупатель Веры — не медианный владелец, а верхняя часть: фирма с персоналом и потоком звонков. Отбирать по признакам потока (объявления о найме, реклама, отзывы), а не по «русскоязычности».
