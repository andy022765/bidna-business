# Язык вопроса решает, появятся ли местные поставщики вообще, а IP решает, какой страны

Контролируемая проба (234 запуска, ChatGPT в браузере без логина и через API, четыре страны выхода, шесть языков, август 2026) показала: когда язык вопроса совпадал со страной, глобальный бренд выиграл 1 раз из 24, а на английском с тех же подключений местные поставщики в Эстонии и Турции не появились ни разу из 6. При фиксированном языке смена IP меняла страну поставщиков: турецкий вопрос из Берлина получил немецких поставщиков. В контрольной категории эффекта языка не было, авторы связывают это с тем, регулируется ли категория на уровне страны. Выборка мала, но механизм прямо касается наших клиентов.
