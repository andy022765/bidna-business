# Статус выгорания креатива в Meta доступен только для групп объявлений с одним креативом

Справка: «this feature is only available for ad sets with one creative except those with advantage+ catalog ads, dynamic creative, or meta advantage+ app campaigns. it is not available with the sales objective before an ad set is active». У нас в группе 3–4 объявления, а прошлых объявлений, с которыми сравнивать цену результата, нет. Значит, статуса «creative fatigue» в первом тесте не будет, и замену креатива придётся предлагать по нашим правилам: частота, CTR, цена звонка.
