# B2B-лид в Meta в 2025 стоил $138–145 (Instagram/Facebook), с холодной аудиторией — $166, с ретаргетингом — $120; дешёвый лид не значит дешёвый клиент

Metadata.io: 153 B2B-рекламодателя, $57.6M расхода, 2025 год, агрегаты взвешены по расходу, срез публикуется только при ≥5 рекламодателях и ≥$50k. CPL: Facebook $145, Instagram $138; холодные аудитории на Facebook $166, ретаргетинг $120; видео дороже (около $225 на Facebook). CPM $15.50/$18.25, конверсия клика в лид 2.6%/4.0%. По выдаче поиска из того же отчёта: цели в компаниях 51–200 человек дороже крупных. У 42 из 132 рекламодателей не было сигнала из CRM, то есть их «успех» измерялся только ценой лида.

Аудитория здесь — компании (в основном SaaS-продажи), а не владельцы микробизнеса по языковому таргету, поэтому переносим как верхнюю границу. Итог по двум источникам: для нас разумный коридор планирования $30–170 за лид, свой CPL надо мерить в первые две недели.
