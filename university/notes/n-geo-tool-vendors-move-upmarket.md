# Лидер рынка ушёл в крупный бизнес: у Profound больше нет публичного платного тарифа

На странице цен Profound (24.09.2026) остались только бесплатный пробный период на 7 дней и Enterprise «по запросу»; в релизе Series D — больше 1 000 корпоративных клиентов и доля Fortune 500. Внутренние документы (`CLAUDE.md`, `shtab/issledovanie/razvedka-2026-09-19/svod.md`, `shtab/issledovanie/voronka-2026-09-20/osnovaniya.md`) ещё называют «Profound $99 / от $499» — это устарело. Рынок раскалывается: наверху корпоративные платформы с агентами, внизу инструменты за $20–100 для самостоятельной работы. Середина — «сделано за вас для одного местного бизнеса» — остаётся за агентствами. Это и есть наше место, а не инструмент.
