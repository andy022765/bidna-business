# С апреля 2026 цель «максимум квалифицированных лидов» недоступна для новых кампаний без Conversions API, для действующих ограничение — с августа 2026

Справка «About performance goals for lead ads» (782657799338685, извлечено 27.09.2026): с апреля 2026 новую кампанию с целью maximize number of qualified leads (раньше Conversion Leads) нельзя создать без интеграции Conversions API; действующие кампании затронуты с августа 2026. Цели лид-рекламы: максимум лидов, максимум квалифицированных лидов, максимум лидов через переписку (вводится постепенно), максимум ценности конверсий. Квалифицированный лид — лид, за которым последовало заданное рекламодателем событие ниже по воронке. Самоотчёт Meta: −21% к цене качественного лида для инстант-форм с CRM-интеграцией (A/B на 567 рекламодателях, 13–27.01.2025) и −9,5% для форм на сайте (69 рекламодателей, 21.08–14.09.2025).
