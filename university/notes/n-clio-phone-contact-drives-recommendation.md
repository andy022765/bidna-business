# Потенциальные клиенты юристов, поговорившие с человеком по телефону, в 3+ раза чаще готовы рекомендовать фирму, чем в среднем

Готовы рекомендовать фирму только 12% тайных покупателей. У поговоривших с человеком по телефону этот показатель более чем в 3 раза выше среднего по всем каналам и почти в 8 раз выше, чем у тех, кому только оставили голосовое сообщение. Это самоотчёт тайных покупателей, а не поведение реальных клиентов. Вывод для Веры: разговор сразу ценнее перезвона и голосового, но это разговор с человеком — про ИИ этот замер ничего не говорит.
