# Три из пяти потенциальных клиентов юристов готовы говорить с чат-ботом, только если можно перейти к человеку

По опросу Clio 51% считают чат-бота полезной точкой входа, больше половины готовы задавать ему простые вопросы. Со сложными делами предпочитают человека. 60% будут пользоваться ботом только при возможности переключиться на человека. Чат-боты стоят у 7% юрфирм. Это совпадает с Gartner: главный страх — потерять доступ к человеку.
