# Группа объявлений Meta выходит из обучения, когда доставка стабильна, — по справке обычно после ~50 результатов за 7 дней после последней значимой правки

Справка Meta (статья 112167992830700, текст на 27.09.2026): обучение идёт при создании объявления или группы и после каждой значимой правки; в колонке «Доставка» стоит «Обучение». Выход — «как только группа может показываться стабильно», и это «обычно» происходит после примерно 50 результатов за неделю после последней значимой правки. Результат — то самое событие оптимизации, на которое настроена группа (у нас — звонок). Порог ориентировочный: слово «обычно», методика выбора числа 50 не раскрыта. Для Shops ads отдельный порог: 17 покупок на сайте и 5 через Meta. В Ads Manager можно добавить колонки «Last significant edit» и «Results», чтобы видеть, сколько набрано с последней правки. Статья про Learning limited (269269737396981) тем же числом задаёт и обратную сторону: группа получает статус, когда ей «вряд ли» набрать ~50 событий за неделю.
