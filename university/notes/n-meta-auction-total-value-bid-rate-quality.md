# Аукцион Meta выбирает объявление с наибольшей «общей ценностью» при минимальной цене: ставка, оценочная вероятность нужного действия и качество рекламы

Справка Meta (430291176997542): аукцион проходит при каждой возможности показа; в нём участвуют объявления, в чью целевую аудиторию попадает человек. Побеждает объявление с наибольшей total value, с учётом минимальной цены (price floor). Total value складывается из трёх факторов. Первый — ставка (сколько рекламодатель готов платить за результат). Второй — estimated action rates, вероятность, что этот человек совершит нужное действие именно с этим объявлением. Третий — ad quality, качество по отзывам людей (просмотры, скрытия) и по низкокачественным признакам: утаивание информации, сенсационные формулировки, приманки для вовлечения. Формулы и весов справка не даёт. Meta оставляет за собой корректировки аукциона (качество, тесты, закон, региональные издержки, правила), но больше ставки не возьмёт.
