# Живой ресепшен стоит $3,45–5 за минуту или $7–10 за звонок, ИИ-ресепшен — $0,15–0,50 за минуту

Арифметика по снимкам 24.09.2026: Ruby $250/50 мин = $5,00, $1 725/500 мин = $3,45 за минуту; Smith.ai операторы $300/30 = $10, $2 100/300 = $7 за звонок. ИИ: Rosie $149/1 000 мин = $0,15, CallSetter $0,40–0,50 за минуту. Наша Вера $199/1 000 мин = $0,20 за минуту при себестоимости около $0,094. Сравнение с людьми показывает масштаб экономии, но покупатель, выбирающий ИИ, сравнивает с ИИ, а не с Ruby.
