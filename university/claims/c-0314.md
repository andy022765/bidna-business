# Себестоимость минуты ИИ-голоса у агентства на HighLevel того же порядка, что у нас: ИИ-сотрудник $97 в месяц на клиента без лимита (Growth $50 — 100 минут), телефония отдельно, а клиенту агентство может выставлять фиксированную цену за минуту (пример вендора — $0,10); поэтому конкуренция с англоязычными агентствами «под ключ» идёт не ценой минуты

## Context

Цены платформы; сколько реально берут агентства с клиентов, из этого источника не видно. Смежно с c-0512 (ветка prodazhi/kanaly: интеграторам на HighLevel white-label Веры интересен только тем, чего нет в их стеке); здесь — следствие для нашей цены.

## Evidence walk-through

Первоисточник цен платформы. «Много и дешевеют» — вывод, отсюда M.

## Counter-evidence / edge cases

Качество таких агентств низкое, и рынок может сам разделиться на дешёвое и надёжное — тогда давление цены слабее.

## Implication for project (подробнее)

В разговоре с владельцем, которому предлагали «бота за $297», объяснять разницу составом работ и приёмкой, а не спорить о цене минуты.
