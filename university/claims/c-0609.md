# По стандарту FTC из дела Air AI «обещание заработка» — любое утверждение, из которого выводится конкретный уровень продаж, роста или дохода, включая калькуляторы потерь и истории клиентов с цифрами; его можно делать только с письменным обоснованием на момент заявления и раскрытием типичных результатов

## Context

Приказ связывает только Air AI, но FTC формулирует в нём стандарт, который применяет к другим (ср. Cox Media Group 2026, n-ftc-ai-marketing-service-deceived-smb).

## Evidence walk-through

H для содержания стандарта (первоисточник). Применимость к нам — через §5 FTC Act и Endorsement Guides, которые обязательны для всех.

## Counter-evidence / edge cases

Business Opportunity Rule к нам не относится (мы не продаём бизнес-возможность перепродажи), но Air AI получила и обвинения по §5 и TSR, которые общие.

## Implication for project (подробнее)

Калькулятор «сколько вы теряете на пропущенных звонках» с итоговой суммой — это Earnings Claim; держать его можно только с методикой и оговоркой, что это оценка по вводным клиента, а не обещание. Кейсы с цифрами — только с типичным результатом рядом. «Продажи растут» без цифры формально не Earnings Claim, но остаётся объективным утверждением по §5 FTC Act, которое тоже требует основания (contr-060).

В правило анти-гарантии (память feedback-anti-guarantee-refined) добавить: цифра результата допустима только с методикой и типичным результатом; калькуляторы — с пометкой «оценка по вашим вводным».
