# OAI-SearchBot, PerplexityBot и Claude-SearchBot — индексирующие обходчики поиска, а не признак живого вопроса; прямой сигнал «кто-то спросил и движок пошёл к нам» дают только ChatGPT-User, Perplexity-User и Claude-User

## Context

Официальные документы трёх вендоров на сентябрь 2026.

## Evidence walk-through

OpenAI: OAI-SearchBot для показа в поиске, ChatGPT-User не для автоматического обхода; Perplexity: PerplexityBot для результатов поиска, Perplexity-User по вопросу пользователя; Anthropic: Claude-SearchBot индексирует, Claude-User по вопросу. Первоисточники, H.

## Counter-evidence / edge cases

Вендор может менять поведение ботов; часть пользовательских заходов может идти без отдельного агента.

## Implication for project (подробнее)

Правка счётчика (полоса ГОЛОС): отдельная графа «поисковый индекс». Внутренний документ PLAN-SVOYA-VIDIMOST и заметка о счётчике относят SearchBot к «живому вопросу» — это ошибка (contr-011). Клиенту промежуточный показатель формулировать так же, в три шага.
