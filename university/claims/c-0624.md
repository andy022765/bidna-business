# Узкое место роста через 6–12 месяцев — часы присмотра по абонементам и запуск Видимости: при 3 часах на клиента 50 активных клиентов съедают 150 часов в месяц, поэтому присмотр должен быть не больше 1.5 часа на клиента Веры и 2–3 часов на клиента Видимости, а запуск Видимости — сокращён с ~23 часов

## Context

Модель эксперимента, отток 3–5% в месяц.

## Evidence walk-through

M: арифметика на допущениях.

## Counter-evidence / edge cases

Если клиенты не используют часы правок, нагрузка ниже.

## Implication for project (подробнее)

В абонентку включать не «часы правок», а ограниченный результат (например, одна правка в месяц + отчёт), автоматизировать отчёты и проверку расшифровок. «1 час правок» в $199 и «2 часа» в $399 при росте базы съедают мощность двоих быстрее, чем запуски.
