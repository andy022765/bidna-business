# SMS-дожим Доводчика требует регистрации каждого клиента как отдельного бренда A2P 10DLC с работающим сайтом, политикой конфиденциальности и условиями SMS-программы, а маркетинговые сообщения — письменного согласия; устного согласия в звонке для дожима недостаточно

## Context

Операторы исполняют правила CTIA через регистрацию 10DLC; незарегистрированный трафик фильтруется.

## Evidence walk-through

H — документация Twilio (поставщик, через которого идут SMS) и CTIA (другой агент).

## Counter-evidence / edge cases

Toll-free номера регистрируются по другой процедуре (verification), но требования к согласию те же. Можно не делать SMS вовсе и дожимать почтой и мессенджерами — это снимает весь блок.

## Implication for project (подробнее)

Наш sms.md годится только для одного сервисного текста по устной просьбе. Для Доводчика нужен отдельный путь: у клиента — страница политик и форма согласия (чекбокс) или SMS-опт-ин, регистрация бренда на установочном звонке (EIN, адрес, сайт), срок запуска с учётом одобрения. У владельцев, у которых только Instagram, SMS-Доводчик без сайта невозможен — для них дожим через почту и мессенджер после их сообщения.

Решение за Андреем: включать ли SMS в комплект Веры или оставить только почту + Telegram/WhatsApp после входящего. Если включать — чек-лист установочного звонка дополняется 5 пунктами (EIN, адрес, сайт, политики, форма согласия).
