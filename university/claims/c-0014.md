# Язык вопроса почти не влияет на то, назовёт ли ассистент исполнителей вообще: по-английски названы исполнители в 86% ответов (6.3 имени), по-русски в 80% (4.7); у людей — 98% против 93%

## Context

Замер калибровки v1, API и люди. Поэтому «две версии сразу» из плана снято: русский первым, английский вторым заходом (следующий квартал).

## Evidence walk-through

Собственная выборка вопросов на тему нашей услуги.

## Counter-evidence / edge cases

Число имён в ответе на английском выше (6.3 против 4.7), значит конкуренция за место на английском плотнее.

## Implication for project (подробнее)

Для русскоязычного владельца решать язык страниц по рынку, а не по «ИИ лучше понимает английский». Русская страница — то, чего нет у вендоров вроде Retell. Но клиенты наших клиентов — американцы, поэтому для их видимости нужен английский. Это разные задачи: наша видимость у владельцев против видимости клиента у его покупателей. Для клиента Видимости вопросы замера — на языке его покупателей: у большинства американский рынок, английский.
