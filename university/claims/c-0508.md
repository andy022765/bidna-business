# Холодные SMS владельцам как канал привлечения для нас закрыты: по правилам операторов (CTIA) маркетинговые сообщения идут только после opt-in с письменным согласием, купленные и собранные списки запрещены

## Context

США; правила операторов поверх TCPA.

## Evidence walk-through

Первичный отраслевой документ с прямыми требованиями; совпадает с внутренним вердиктом по SMS от 14.09 (одно сообщение не туда — от $500 по TCPA).

## Counter-evidence / edge cases

B2B-номера формально могут быть вне части правил TCPA, но оператор фильтрует трафик без разбора B2B/B2C.

## Implication for project (подробнее)

Ничего не менять в продукте; в продаже не обещать клиенту «массовые SMS по вашей базе» без его подтверждённого согласия абонентов.
