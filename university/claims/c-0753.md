# Aggregated Event Measurement больше не требует ранжировать 8 событий на домен и верифицировать домен ради настройки событий: вкладку AEM из Events Manager убрали, домен конверсии при создании кампании не выбирается; события CAPI всё ещё могут обрабатываться в пределах ограничений AEM

## Context

Справка «About Meta's Aggregated Event Measurement» (721422165168355), извлечено 27.09.2026. AEM — протокол Meta для измерения событий пользователей iOS 14.5+.

## Evidence walk-through

Справка перечисляет четыре изменения для веб-кампаний: не нужно ранжировать 8 событий на домен, вкладка AEM удалена, верификация домена для настройки событий не требуется, домен конверсии при создании кампании не выбирается. Оговорка: события через CAPI тоже могут обрабатываться в пределах ограничений AEM. H.

## Counter-evidence / edge cases

Справка пишет «when you have access» — изменение могло дойти не до всех аккаунтов. Документация CAPI пишет, что event_source_url должен совпадать с верифицированным доменом, — это расходится с отменой обязательной верификации; проверить при установке.

## Implication for project (подробнее)

- План пикселя для ГОЛОСА — без шага «8 событий».
