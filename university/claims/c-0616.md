# Полная переменная себестоимость минуты Дежурного на нашем стеке — около $0.103–0.107: ElevenLabs $0.08 + LLM ≈$0.014 (замер $0.0943) плюс входящая Twilio $0.0085 и, возможно, Media Streams $0.0044; телефония — 8–12% цены минуты

## Context

Замер 16.09 — 125.9 минут тестовых звонков; реальные звонки клиентов могут быть длиннее или с другим LLM.

## Evidence walk-through

M: цена ElevenLabs и Twilio — официальные (H), LLM-часть и Media Streams — из одного замера и допущения.

## Counter-evidence / edge cases

При смене LLM (дороже Gemini) цена минуты растёт; при длинном промпте (66 КБ) — тоже.
