# Через API ИИ-ассистенты без принудительного поиска ходят в интернет не всегда (Claude 180 из 192, ChatGPT 275 из 312, Perplexity 132 из 156), а в приложениях у людей поиск включался всегда — поэтому замер видимости надо гнать с принудительным поиском

## Context

В приложениях: ChatGPT без логина 12 из 12, с логином 7 из 7, Claude 27 из 27, AI Mode 12 из 12, Perplexity 31 из 31. Часть ранних прогонов мерила «полез ли ассистент в интернет», а не «видно ли клиента».

## Evidence walk-through

Собственный замер: журналы поисков в ответах API и сохранённые страницы приложений. Для AI Mode источники рисуются скриптом, поэтому «поиск неизвестен» — не «поиска не было».

## Counter-evidence / edge cases

Поведение поиска у движков меняется с версиями моделей (OpenAI chat-latest — плавающее имя).

## Implication for project (подробнее)

Смотритель меряет в режиме poisk (tool_choice required у OpenAI, any у Claude). Клиенту говорим: «мы меряем через программные входы нейросетей; это близко к тому, что видит человек, но не равно ему». Обещать «вот что увидит ваш покупатель» нельзя. Фиксировать отпечаток настроек и модель в каждом отчёте клиенту.
