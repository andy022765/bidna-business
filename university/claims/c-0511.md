# Ставки партнёрских комиссий в софте — около 20–40% выручки и часто пожизненно (HighLevel 40% ежемесячно, пока клиент платит; в 250 SaaS-программах Rewardful — в среднем 22–25%); наши предложенные 10–20% разово с первого платежа ниже этой планки, а независимого бенчмарка для агентских услуг нет

## Context

Бенчмарки — софт; агентские услуги с высокой долей ручного труда могут платить меньше. Цифры для услуг из блогов (5–10% или 10–20%) мы не обработали как источники.

## Evidence walk-through

Два вендорских набора (один — условия одной программы, второй — 250 программ без методики) — L.

## Counter-evidence / edge cases

Для посредника без собственного продукта важнее не ставка, а риск для репутации перед клиентом; возможно, «подарок клиенту» (бесплатный замер) ценнее процента.

## Implication for project (подробнее)

Решение по ставке — за Андреем; до решения на разговорах с посредниками не называть цифру, а спросить их ожидания.
