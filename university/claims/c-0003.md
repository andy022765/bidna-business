# 88.6% цены минуты Веры — фиксированная плата платформы, не зависящая от языка; английская минута не дороже русской (около $0.098 против $0.100)

## Context

Разбор 17.09 по нашим 68 разговорам. Токены — около 11.4% цены минуты. Русский текст даёт в 1.11 раза больше токенов на то же содержание: замер на 394 парах RU/EN с наших же лендингов.

## Evidence walk-through

Внутренний расчёт по нашим счетам, сделан один раз. Английских живых звонков у нас не было: все 68 разговоров русские.

## Counter-evidence / edge cases

Если английские разговоры окажутся длиннее хотя бы на полминуты, выгода съедается многократно: одна лишняя минута — 440–490 кредитов.

## Implication for project (подробнее)

Язык не аргумент в цене Веры. Английская линия для клиентов стоит работы (второй паспорт агента, 17–27 часов), а не дороже по минутам. Длина разговора влияет на цену в 30–100 раз сильнее токенов. Английскую Веру для клиентов считать по той же себестоимости минуты, отдельной цены за язык не вводить.
