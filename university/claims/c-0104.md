# llms.txt, особая разметка и schema.org — гигиена без доказанного влияния на цитирование в ИИ; Google прямо пишет, что Поиск их для ИИ-ответов не использует

## Context

Для Google — официальная позиция; для ChatGPT/Perplexity — независимые замеры на больших выборках, но на крупных сайтах.

## Evidence walk-through

Google mythbusting: llms.txt и особая разметка не нужны, Поиск их игнорирует. Ahrefs: 1 885 страниц с контролями — нет роста; 97% llms.txt никто не читает. SE Ranking на 300 тыс. доменов — нет связи. Sharma: GEO-балл не связан с находимостью. H.

## Counter-evidence / edge cases

Для страниц, которые ИИ ещё не видит, schema может помогать разбору (не проверено). llms.txt читают агенты для кода — к местному бизнесу не относится. Наш llms.txt Perplexity цитировал — как обычную страницу.

## Implication for project (подробнее)

На лендинге «Открытая дверь» ($300) и «Страница, которую читают нейросети» — держать как гигиену и замену несуществующего сайта; не обещать от них видимости. В разговоре о конкурентах: «балл 0–100» у чужих аудиторов — не доказанный показатель.
