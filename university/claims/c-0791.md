# Advantage+ creative может менять текст и медиа наших объявлений: часть улучшений включена по умолчанию (в том числе text improvements), генеративные улучшения перефразируют надписи и добавляют промо к кнопке, часть выключается только в расширенном превью, а настройка аккаунта «тестировать новые оптимизации» применяет тестовые улучшения поверх выбора в объявлении

## Context

Справка на 27.09.2026. Статья «About Advantage+ creative» обрезана инструментом — пункты о текстовых улучшениях, переводе и комментариях не получены; их содержание частично восстановлено по соседним статьям.

## Evidence walk-through

Три официальные статьи и строки из трёх соседних дают согласованную картину: изменения возможны, часть включена по умолчанию, есть уровень аккаунта. H.

## Counter-evidence / edge cases

Какие улучшения включает по умолчанию коннектор Meta Ads при создании через API, из справки не видно. По документации Marketing API (to-follow) каждое улучшение включается или выключается отдельно, и одно из них (adapt_to_placement) по умолчанию включено.

## Implication for project (подробнее)

Анти-гарантия и запрет на цифры держатся только если текст в показе совпадает с утверждённым. Поэтому проверка превью — обязательный шаг, а не формальность.
