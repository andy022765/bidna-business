# У местного бизнеса попадание в ответ ИИ связано с документированностью в сети — собственный сайт, объём отзывов, цены текстом, упоминания на сторонних сайтах; рейтинг влияет на порядок, а не на вход

## Context

Главная опора — предрегистрированный аудит Бали (кафе и рестораны, английский, API). Для сервисных бизнесов в США прямого аналога нет.

## Evidence walk-through

Бали: сайт OR 1,92, объём отзывов 1,64, цена 1,54, упоминания 1,44; рейтинг незначим на входе (0,89) и значим для первого места (1,17). BrightLocal и Search Atlas дают то же направление, но слабой методикой. Google официально называет известность (ссылки, отзывы) фактором местного ранжирования. M, потому что ключевой источник один и наблюдательный.

## Counter-evidence / edge cases

Ассоциации, не причины: ухоженные бизнесы делают всё сразу. Для услуг на выезде (кровля, клининг) источники другие — больше каталогов (Angi, Yelp, отраслевые). Проверить на своих данных.

## Implication for project (подробнее)

Перечень работ на лендинге (одинаковые данные, страницы с ценой текстом, чужие каталоги) совпадает с этими факторами — держать. Добавить явный блок «объём отзывов» с процессом у клиента (c-0116). Не обещать, что высокий рейтинг сам по себе выведет в ответ.
