# Бухгалтер с лицензией CPA может законно брать у нас реферальную комиссию только при письменном раскрытии клиенту и не по клиентам, которым делает аудит, ревью, компиляцию для третьих лиц или проверку прогнозной отчётности

## Context

Кодекс AICPA (ред. сентябрь 2025). Штатные правила могут быть строже; для юристов (правила адвокатских палат штатов) и страховых агентов (законы штатов о комиссиях) — отдельная проверка, не сделана.

## Evidence walk-through

Прямой нормативный текст — H для CPA; для остальных типов посредников вывод не переносится.

## Counter-evidence / edge cases

Отдельные штаты исторически ограничивали комиссии CPA сильнее кодекса; юристы по правилам профессиональной этики обычно не могут делить гонорар и должны раскрывать конфликт интересов — нужно проверить до предложения юристам.

## Implication for project (подробнее)

Перед первым разговором с юристом-партнёром — проверить правила палаты его штата (в to-follow). Бухгалтеры — первый тип партнёра, как наименее зарегулированный при раскрытии.
