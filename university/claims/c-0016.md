# Доля роботов в нашем прозвоне (7 из 19 = 37%, 8 из 17 = 47%, 15 из 18) — свойство списка, а не рынка: все 60 целей первого списка взяты с витрин вендоров голосовых ботов

## Context

Поле vendor есть у всех 60 записей misheni-2026-09-21/spisok.json: Numa 11, Slang 6, Avoca 5, Sameday 4, Arini 4, Rondah 4 и далее. Методика воронки 20.09 прямо брала цели со страниц кейсов вендоров (voronka.md:37). 24.09 холодные медспа ещё не звонили.

## Evidence walk-through

Прямая проверка поля источника в списке. Отозвано самим ШТАБОМ 23.09.

## Counter-evidence / edge cases

Нет. Это вывод о методике, а не о рынке.

## Implication for project (подробнее)

Плотность ИИ-ботов в малом бизнесе США нам неизвестна, и называть её нельзя ни в продаже, ни в выводах. Для внешних исследователей: вендорские витрины («наши клиенты») помечать bias.protocol_sponsored и не использовать как рыночную статистику. Сторонняя оценка «каждый шестой малый бизнес имеет робота или IVR» (Talkdesk, 2025) по первоисточнику не проверена. Любую «долю» из нашей выборки сверять с тем, как отбирался список.

_Источник — внутренние наработки проекта (ключ сессии `vnutr`), не внешний первоисточник. Пути в `sources` даны относительно корня проекта._
