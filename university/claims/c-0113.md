# ChatGPT опирается на собственный поисковый индекс (OAI-SearchBot) и, по данным 2025 года, сильно совпадает с выдачей Bing; присутствие в Bing (Bing Places, Bing Webmaster Tools) — дешёвая страховка, но не «ChatGPT = Bing»

## Context

Замер Seer — февраль 2025, 500+ ссылок, интерфейс ChatGPT; с тех пор OpenAI развил свой индекс и, по отраслевым сообщениям, брал и результаты Google.

## Evidence walk-through

Seer: 87% совпадений с Bing, 56% с Google. OpenAI: OAI-SearchBot — свой обходчик для поиска. Данных 2026 года с методикой не нашли. L.

## Counter-evidence / edge cases

Если ChatGPT сместился на свой индекс, вклад Bing снизился.

## Implication for project (подробнее)

Пункт «Bing Places + Webmaster» — 20–40 минут работы; включить в запуск без отдельной цены.
