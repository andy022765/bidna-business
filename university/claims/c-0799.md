# Meta запрещает ложно выступать от имени известного бизнеса и использовать имя или образ публичного человека (brand-bait, celebrity-bait), поэтому в рекламе Видимости ChatGPT, Claude и Perplexity — только объект замера, без логотипов, «рекомендовано ChatGPT» и намёка на партнёрство

## Context

Стандарт сообщества «Prohibited Commercial Practices»; рекламный стандарт называет это «unauthorized endorsements».

## Evidence walk-through

Запрет — первоисточник. Уверенность M: применение к упоминанию ИИ-движков — наше толкование, правило об IP не прочитано.

## Counter-evidence / edge cases

Правило об интеллектуальной собственности третьих лиц может ограничивать и упоминание товарных знаков в тексте, не только логотипы.

## Implication for project (подробнее)

Для режима «План» второй кампании: пункт «чужие бренды — только как объект замера».

Связанные claims: c-0203.
