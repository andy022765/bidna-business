# Модель ранжирования рекламы Meta (GEM) учится на рекламных и органических взаимодействиях всех поверхностей, потому что конверсии редки, и получает на вход представление креатива; значит, содержание креатива влияет на то, кому покажут рекламу, а маленький рекламодатель получает прогноз, построенный не только на своих событиях

## Context

Инженерный блог Meta, 10.11.2025 (изменено 02.12.2025). Признаки: последовательности действий человека (тысячи событий) и атрибуты пользователя и объявления (возраст, место, формат, «creative representation»). Знания передаются сотням моделей ранжирования. Статьи блога 2026 года (sequence learning 05.08.2026, GEM training 03.08.2026, Adaptive Ranking Model 31.03.2026, Hierarchical Interest Representation 15.07.2026) просмотрены и стоят в to-follow; последняя — исследование, где контент страницы и товаров рекламодателя должен помогать при редких сигналах, но статус внедрения не ясен.

## Evidence walk-through

Наличие признака креатива — первоисточник. Вывод о влиянии на показ — логичный, но вес признака неизвестен, поэтому M.

## Counter-evidence / edge cases

Приросты GEM (+5% и +3% конверсий) — самоотчёт. Модель может почти не использовать креатив для рекламодателя с малым числом показов — Meta этого не раскрывает.

## Implication for project (подробнее)

1. Инструкция §6 — переформулировать (см. implication).
2. Креативы: сегмент видно без звука и в первом кадре (совпадает с правилом про обложку видео).
