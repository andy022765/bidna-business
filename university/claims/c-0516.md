# Бюджет большинства малых бизнесов на маркетинг — меньше $1,000 в месяц, а главный критерий выбора внешнего партнёра — цена, затем доказанный результат и прозрачность; абонентка $199–399 вписывается в этот масштаб, а разовый запуск $1,000–2,500 требует лестницы и доказательства, которое человек проверит сам до оплаты

## Context

Один вендорский опрос; бюджет маркетинга — не единственный кошелёк (запуск Веры может идти из «операционных» денег).

## Evidence walk-through

Опрос 300+ владельцев без раскрытой методики — L.

## Counter-evidence / edge cases

Русскоязычные владельцы с выручкой $50k+/мес (прежний профиль) могут иметь бюджеты выше; у ниш на звонках (ремонт, перевозки) — стоимость пропущенного заказа выше годовой абонентки.

## Implication for project (подробнее)

Решение о рассрочке запуска — за Андреем.
