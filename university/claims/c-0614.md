# Для клиник, подпадающих под HIPAA, вся цепочка Веры требует BAA: Twilio подписывает его только на платных Security или Enterprise Edition, ElevenLabs — только на Enterprise; значит, Вера для клиник со страховыми заявками — отдельный продукт с неизвестной пока себестоимостью

## Context

HIPAA обязывает covered entity иметь BAA со всеми подрядчиками, обрабатывающими PHI.

## Evidence walk-through

H — страницы поставщиков.

## Counter-evidence / edge cases

Цены Enterprise не опубликованы.

## Implication for project (подробнее)

Подтверждает и уточняет c-0021 и KLINIKI-I-HIPAA.md. Продавать сейчас можно клиникам без электронных страховых заявок (не covered entity). Клиникам со страховками — ничего не обещать, пока не посчитана цепочка с Enterprise-тарифами.
