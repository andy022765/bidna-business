# Для малого бизнеса главные барьеры ИИ в 2025 — сомнение в качестве, цена и правовой риск/безопасность данных, а у самых маленьких фирм — инерция «работает — не трогай»; «не понимаю, что это» уходит на второй план

## Context

Опросы 2024–2025 по США (Salesforce — глобальный). Сравнение с 2023 есть только у Торговой палаты.

## Evidence walk-through

Торговая палата (3,870, онлайн) даёт структуру барьеров неиспользующих; NFIB — инерцию у микрофирм; Salesforce — заботы использующих; Thryv — долю недоверия (слабо). Направление совпадает у всех, но точные доли зависят от выборки — M.

## Counter-evidence / edge cases

Порядок столбцов барьеров Торговой палаты восстановлен нами по тексту. Для русскоязычных владельцев отдельных данных нет; у них может быть сильнее недоверие к подрядчикам, а не к ИИ.

## Implication for project (подробнее)

Обновить docs/otrabotka-vozrazheniy.md (через «ГОЛОС»): блоки «работает ли», «сколько стоит», «где мои данные», «мне и так нормально» — в таком порядке частоты.
