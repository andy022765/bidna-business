# Списки компаний в ответах ИИ-ассистентов нестабильны: тот же человек, движок и вопрос через 6 дней совпадают по названным компаниям лишь на 13–30% (Claude 13%, AI Mode 20%, ChatGPT 25%, Perplexity 30%), два прогона программы через 10 часов — на 35%

## Context

Калибровка v1 (16, 17, 22.09): люди 115 ответов, программа 660. Приложение против программы — 13–33% общих компаний. Программа сама с собой утром и вечером (178 пар) — 35%. Между днями программа совпадает на 23–47%. Цифры 11–28% и 28% из записи 17.09 — ранняя версия до сведения названий по опорному слову. Лендинг /visibility/ всё ещё цитирует «28% через десять часов».

## Evidence walk-through

Собственный замер с единым правилом разметки, три дня, два независимых канала. Для наших вопросов уверенность H, для обобщения на другие ниши — M.

## Counter-evidence / edge cases

Совпадение по опорному слову названия — приближение: одну фирму пишут по-разному. Выборка вопросов — наши, про нашу услугу и три знакомых бизнеса.

## Implication for project (подробнее)

Надёжно различается только «называют или нет», а не «на сколько процентов чаще». В отчётах клиенту — никаких процентов роста и мест в списке. Замер — несколько прогонов на движок («назвали хотя бы в одном из N»). Квартал вместо месяца оправдан измеренным шумом. На лендинге видимости эти цифры уже опубликованы как наш замер. Гарантию видимости держать на бинарном сигнале: ноль упоминаний за квартал — полный возврат (contr-002). На лендинге обновить 28% → 35% или указать дату замера.
