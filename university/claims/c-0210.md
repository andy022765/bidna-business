# Типовая упаковка GEO для местного бизнеса: дешёвый вход → разовый запуск → помесячная абонентка

## Context

Две публичные упаковки агентств под местный бизнес США (одна по-русски) плюс бесплатные проверки у инструментов.

## Evidence walk-through

Ermin: аудит $35 («ручной замер по нише и городу», остаётся у клиента) → поддержка от $900/мес. Citevio: запуск $1 900–7 500 (исходный замер со скриншотами, доступ ИИ-ботам, разметка, Bing и IndexNow, пересборка Google-карточки, единые имя-адрес-телефон) → $1 400–5 500/мес, отмена в любой день, годовая −15% вперёд. Инструменты: бесплатные пробные периоды и проверки. Две агентские точки — M.

## Counter-evidence / edge cases

Помесячная отмена у Citevio сочетается с возвратом запуска только по событию — деньги агентства защищены запуском. У нас квартал вперёд решает ту же задачу (защита от «три месяца работали и всё отдали», решение 11.09). Модели эквивалентны по смыслу, различаются подачей.

## Implication for project (подробнее)

1. Если оставляем квартал вперёд — писать, почему именно квартал (срок проявления эффекта).
2. Нулевой замер как вход уже есть у нас в замысле (калибровка, «зафиксированный ноль»); его можно сделать публичным входом Видимости по примеру $35-аудита.
3. Состав запуска описывать пунктами, как у Дежурного в `docs/pricing.md`.
