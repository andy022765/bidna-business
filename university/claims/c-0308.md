# SMS-напоминание о записи повышает явку относительно отсутствия напоминания (Кокрейн 2013: RR 1,14; 67,8% → 78,6%) и работает так же, как звонок-напоминание, но дешевле; доказательства есть только для медицинских приёмов, а независимых РКИ о том, что SMS-дожим повышает конверсию лидов малого бизнеса, мы не нашли

## Context

Медицина, 1993–2012, низкое–умеренное качество, неоднородность. Для салонов и автосервиса — аналогия.

## Evidence walk-through

Систематический обзор Cochrane с метаанализом — лучший тип доказательства в этой ветке, но старый и узкий. M.

Заметки: [n-cochrane-sms-raises-attendance], [n-cochrane-sms-equals-call-reminder], [n-cochrane-sms-cheaper-per-attendance], [n-cochrane-evidence-healthcare-only], [n-no-independent-evidence-sms-lead-conversion]. Источники: [src-20260924-cochrane-sms-reminders-2013].

## Counter-evidence / edge cases

Метаанализ 2022 (в очереди) может дать другой размер эффекта. Для ниш без визита (юристы, ремонт) напоминание играет меньшую роль.

## Implication for project (подробнее)

В комплекте Веры: напоминание за 24 ч и за 2 ч до визита (SMS для американских клиентов, мессенджер для русскоязычных), подтверждение/перенос одной кнопкой; неявки как метрика в отчёте владельцу.
