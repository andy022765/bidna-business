# Meta советует показывать рекламу со звонком только в рабочие часы (в её эксперименте 8–14.09.2025 это дало +25,4% звонков-конверсий) и предлагает «просьбу перезвонить» тем, до кого не дозвонились; оба инструмента лечат недоступность, которой у круглосуточной Веры нет

## Context

Инструкция по созданию рекламы со звонком (604687010451937) и обзор (378168646496279), извлечено 27.09.2026. Расписание задаётся в Budget & schedule → Show more settings → Set a schedule for ads; по справке — и при дневном, и при общем бюджете. Callback — галочка «via Messenger» (работает, если бизнес пользуется Messenger), включается и выключается во время показа.

## Evidence walk-through

Рекомендация показывать рекламу только в рабочие часы и цифра +25,4% повторены в двух статьях; эксперимент 8–14.09.2025, размер выборки и определение «звонка-конверсии» не раскрыты, Meta сама оговаривает, что результат не гарантирован. Это самоотчёт вендора (bias.protocol_sponsored), поэтому M.

## Counter-evidence / edge cases

Расписание может помогать не только доступностью: в рабочие часы звонят другие люди. Для Веры это не проверено. В каком часовом поясе работает расписание (аккаунт — Лос-Анджелес, Нью-Йорк на три часа впереди), прочитанные статьи не говорят. По статье 1549971302464645 (в очереди) у части рекламодателей callback включён по умолчанию.

## Implication for project (подробнее)

- Чек-лист перед «включай»: callback — выключен или назначен ответственный; расписание — нет.
- В плане для клиентов Веры: «Meta советует крутить звонковую рекламу только когда вы на месте; с Верой это ограничение снимается» — описание механики, без цифры +25,4%.
