# Типичный иммигрантский бизнес микро: медианный заработок иммигранта-владельца $50 тыс. в год, поэтому цена Веры ($1000 запуск + $199/мес) доступна верхней части рынка — фирмам с персоналом и потоком заявок

## Context

Медиана по всем иммигрантам-владельцам инкорпорированных фирм (ACS 2023). Заработок владельца ≠ выручка фирмы.

## Evidence walk-through

Одна цифра из первоисточника, вывод о цене — наше рассуждение. M.

## Counter-evidence / edge cases

В нишах медицины, юристов и стоматологии медиана заметно выше; там цена не барьер. В хэндимене и клининге — наоборот.

## Implication for project (подробнее)

Цена Веры для микро-бизнеса без персонала — 5% его годового заработка только на абонемент; продавать им комплект — терять время. Приоритет — фирмы с 3–20 сотрудниками.
