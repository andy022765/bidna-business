# Движки выбирают разные источники и разных поставщиков, поэтому видимость надо мерить и показывать по каждому движку отдельно, а не одной цифрой «в ИИ»

## Context

Независимо подтверждено в местных, брендовых и общих вопросах, в США, Канаде, Европе и на Бали.

## Evidence walk-through

Jaccard 0,11–0,18 между Google, AIO и Gemini; 0,15–0,25 между четырьмя ИИ по местным услугам; 0,33–0,54 по заведениям Бали; 15 из 38 организаций только в одном движке. H.

## Counter-evidence / edge cases

Верхние агрегаторы и бренды-лидеры общие для всех; для них сходство выше.

## Implication for project (подробнее)

Смотритель уже меряет три движка раздельно — держать. В письме владельцу — таблица по движкам. Не обобщать «ИИ вас не видит» на все движки по одному.
