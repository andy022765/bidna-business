# На русские вопросы без географии Claude отвечает из российского рынка (55% источников в зонах .ru/.by/.kz/.ua), а ChatGPT и Perplexity — нет (0% и 3%); с явным «бизнес в США» доля таких источников падает до 13%

## Context

Замер v2 23.09: шесть замороженных вопросов, 30 ответов. Доля .ru/.by по вопросам: G01 61%, G06 41%, G02 37%, G03 35%, G04 28%, G05 13% (единственный с «бизнес в США»). Вечерний пересчёт по движкам показал, что это свойство Claude.

## Evidence walk-through

Один прогон, 3 ответа на вопрос на движок, поэтому уверенность M.

## Counter-evidence / edge cases

Малая выборка. Поведение Claude с веб-поиском (web_search_20250305) может зависеть от локации запроса: в программе стоит Los Angeles, CA.

## Implication for project (подробнее)

Русскоязычный владелец в США, который спрашивает Claude по-русски, получит советы и исполнителей из России. Для клиентских замеров и страниц: вопросы по-русски обязательно с «в США» или городом. Мерить и отчитываться по движкам отдельно, не одной цифрой. Первоначальный вывод «русский вопрос = российский рынок» отозван. Для Видимости русскоязычному клиенту — отдельная проверка Claude.
