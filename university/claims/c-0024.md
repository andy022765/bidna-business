# Замер видимости через официальные API стоит копейки относительно цены услуги: слот из 126 вызовов по трём движкам — около $5, нулевая точка по 6 вопросам (30 вызовов) — $0.79–1.21, оценка на клиента в месяц — $6–12

## Context

Цены вызова: OpenAI около $0.03, Claude около $0.08 (с web_search_20250305), Perplexity около $0.006. Версию поиска Claude 20260209 отвергли: 259 с и около $0.27 за вызов. Лимиты: OpenAI $18, Anthropic $19.50, Perplexity $4.50. 23.09 кошелёк Anthropic опустел посреди прогона.

## Evidence walk-through

Итоговые файлы прогонов и счётчики программы.

## Counter-evidence / edge cases

DataForSEO для AI Overviews и AI Mode не подключён (серая зона). Google AI Mode сейчас только руками. Ручной труд человека в замере не посчитан.

## Implication for project (подробнее)

Себестоимость Видимости $1 500 за квартал — почти целиком наш труд (площадки, страницы, каталоги), а не замер. Готовые трекеры за $29–99 в месяц продают то, что нам стоит доллары, поэтому продаём работу, а не цифру. Бесплатная проверка «кто вместо вас» на лендинге (ChatGPT, 8 имён примерно за 8–9 с) масштабируется, в отличие от бесплатной приёмки звонками. Бюджет API заложить с запасом и держать отдельный ключ; автозапуск на 22.12 не стоит (расписание зашито на сентябрь).
