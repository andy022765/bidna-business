# Сырые цифры «рост в N раз» из GEO-кейсов завышают эффект, потому что сами ИИ-платформы быстро растут; честный кейс требует контрольной группы

## Context

Проверено на трафике из ChatGPT (Glasp) и на цитированиях AI Mode (Ahrefs); для упоминаний местного бизнеса логика та же.

## Evidence walk-through

Glasp: 5,7x всего, 3,5x у нетронутых страниц, чистый скачок ~1,8x и не прошёл плацебо. Ahrefs: сырой +43% в AI Mode почти весь — рост платформы. Обзор: большинство рыночных цифр без контроля. M.

## Counter-evidence / edge cases

Если платформа сжимается (как AIO в 2025–2026), ошибка обратная: работа выглядит хуже, чем есть.

## Implication for project (подробнее)

В плане своей видимости добавить контрольные вопросы; в продажных материалах цифры чужих кейсов не использовать без пометки «без контроля, вендор о себе» (bias.protocol_sponsored).
