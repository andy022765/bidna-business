# Meta рекомендует A/B-тесты не короче 7 дней (до 30) с одной переменной, непересекающейся аудиторией и бюджетом, достаточным для уверенного победителя; тест на $150 за 7–10 дней этому условию по бюджету не отвечает, поэтому сравнение объявлений внутри одной группы — отбор, а не A/B-тест

## Context

Справка 290009911394576. Соседняя статья «About A/B testing» (1738164643098669, в to-follow) не советует тестировать включением и выключением групп вручную: аудитории пересекаются, результат ненадёжен.

## Evidence walk-through

Первоисточник. H.

## Counter-evidence / edge cases

«Достаточный бюджет» Meta числом не задаёт; вывод «$150 недостаточно» — из нашей арифметики (5–10 звонков в неделю, c-0700).

## Implication for project (подробнее)

1. Инструкция §5 — слово «победитель» заменить на «лучшее по цене звонка при N звонках».
2. A/B-тесты — со второй кампании и только при бюджете на десятки результатов на вариант.
