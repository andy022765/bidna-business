# Словами «гарантия возврата денег» (Money Back / Satisfaction Guarantee) можно называть только безусловный возврат полной цены по требованию; наши условные возвраты (Видимость — «не назвали ни разу за квартал», Вера — плата за запуск после двух неудачных исправлений) нужно называть условием возврата и печатать ограничения рядом с ценой

## Context

Руководство FTC применяется к рекламе любой гарантии (§239.1), в том числе B2B-услуг.

## Evidence walk-through

Прямой нормативный текст — H.

## Counter-evidence / edge cases

Руководство, а не правило с прямыми штрафами; но FTC преследует искажения по разделу 5.

## Implication for project (подробнее)

Сверить с внутренним противоречием contr-007 (гарантии Веры на лендинге против оферты).
