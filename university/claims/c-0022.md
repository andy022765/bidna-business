# Для товарного бизнеса открытый доступ ИИ-роботам не даёт цитирования: Frenchies прописали в robots.txt «Welcome AI for citations» и поставили инструмент под цитирование, но по профильным запросам их не называют, а называют девять других брендов

## Context

Разбор 17.09 по первому товарному контакту (шпильки для волос, чек $18–45). Факторы влияния взяты из arxiv 2608.07069 (аудит 4 776 заведений) и arxiv 2601.00912 (Discovery Gap), на них ссылается RAZVEDKA-GITHUB. Внешним исследователям — перепроверить первоисточники.

## Evidence walk-through

Один бренд, один срез. Отсюда уверенность L для обобщения.

## Counter-evidence / edge cases

Доступ может быть необходимым условием, просто недостаточным. «Открытая дверь» (проверка robots.txt и Cloudflare, $300 на лендинге) остаётся полезной как первый шаг.

## Implication for project (подробнее)

Для услуг источник цитаты — сам бизнес (сайт, карточка, каталоги), и наш рычаг прямой. Для товаров источник чужой (обзоры, маркетплейсы, форумы), и из шести рычагов наши только два. GEO для товарного бизнеса продавать как консультацию с помесячной оплатой и без гарантии возврата (решение Андрея 17.09). Первые сдвиги — оценка 12–16 недель против 8–10 у услуг, это не замер. Разделить методику Видимости на две ветки: услуги и товары.
