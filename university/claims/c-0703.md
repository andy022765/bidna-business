# По справке Meta пауза группы — значимая правка, только если длится 7 дней и дольше; короткой паузы в списке значимых правок нет, а пауза отдельного объявления не упомянута вовсе

## Context

Формулировка справки: «pausing your ad set for 7 days or longer (the ad set reenters the learning phase once you unpause the ad set)», и «only a significant edit causes an ad set to reenter the learning phase».

## Evidence walk-through

Вывод о короткой паузе — чтение списка, который Meta называет исчерпывающим для значимых правок. H для группы; для объявления данных нет.

## Counter-evidence / edge cases

Любая правка «как-то влияет на доставку» (та же статья): короткая пауза не сбрасывает обучение, но прерывает показы, и перезапуск доставки может дать скачок цены. Пауза объявления меняет набор объявлений в группе — эффект не описан.

## Implication for project (подробнее)

1. Инструкция §2.7 — поправить формулировку (contr-100).
2. Для паузы до 7 дней отчёт пишет «обучение по справке не сбрасывается», для 7+ — «обучение начнётся заново».
3. Правило «не ставишь на паузу последнее объявление — предлагаешь паузу группы» (§2.5) не меняется.
