# Цена ошибки по TCPA — $500 за каждый звонок или текст без согласия, до $1 500 при умысле, без доказательства ущерба; правила о часах 8:00–21:00 и Do-Not-Call распространяются на тексты, а во Флориде продажный текст — отдельное основание для иска на $500

## Context

Каждое сообщение — отдельное нарушение; иски часто групповые.

## Evidence walk-through

Первоисточники — тексты закона и правил. H.

## Counter-evidence / edge cases

Суды расходятся в том, что считать автодозвоном после Facebook v. Duguid (2021); SCOTUS в McLaughlin v. McKesson (2025) освободила суды от обязательного следования толкованиям FCC — это может сузить или расширить риск (в очереди).

## Implication for project (подробнее)

Одна неудачная рассылка Доводчика на 100 номеров без согласия — риск $50–150 тыс., больше годовой выручки. Поэтому в продукте: расписание отправки по часовому поясу получателя (не раньше 8, не позже 21; для Флориды — проверить §501.616), свой список «не беспокоить» и проверка по реестру для продажных сообщений.

Встроить в Доводчика: окно отправки 8:00–21:00 по TZ номера, журнал STOP, запрет повторного контакта после отказа, документированную процедуру (она же защита «due care» по §227(c)(5)).
