# Отчёты Meta обновляются каждые 15 минут, могут меняться ещё пару дней после окончания рекламы и замораживаются через 28 дней; с 10.06.2025 API, а значит и коннектор, отдаёт действия вне Meta по дате конверсии, а действия на Meta — по дате показа; «досчёт до 7 дней» — не правило Meta

## Context

Лучшие практики Insights API и журнал изменений Marketing API за 2025 год (Meta for Developers); извлечено 27.09.2026. Коннектор Meta Ads читает отчёты через этот же API.

## Evidence walk-through

Лучшие практики Insights API: отчёты обновляются каждые 15 минут, через 28 дней не меняются, после окончания показа метрики «may continue to update for a couple of days». С 10.06.2025 параметры use_unified_attribution_setting и action_report_time игнорируются, время действий — «mixed»: клики и другие действия на Meta — по дате показа, покупки на сайте и другие действия вне Meta — по дате конверсии. M: справка о Commerce Manager (в очереди) пишет, что Ads Manager отчитывается по дате показа, и «пару дней» — не число.

## Counter-evidence / edge cases

Модельные конверсии Meta (статья 311705270326952, в очереди) могут перераспределяться между объявлениями задним числом. К какому типу — «на Meta» или «вне Meta» — относится звонок из объявления, документация не говорит.

## Implication for project (подробнее)

- Отчёт: строка «Ещё обновляется: последние 2 дня».
- Итоги теста — через 2 дня после остановки; сравнение с первым снимком — через 28 дней, чтобы узнать, сколько доливается на нашем аккаунте.
