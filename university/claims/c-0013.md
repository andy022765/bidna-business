# На вопрос «бизнес в США, я один, кто может отвечать за меня по-русски?» ассистенты называют только англоязычные службы ответа с живыми операторами (Ruby, PATLive, AnswerConnect, Answering365, receptionhq и др.) — русскоязычного исполнителя не называет никто

## Context

Вопрос G05 (v2) и U05 (v3, замороженный до 22.12). В v2 G05 — единственный вопрос, где исполнителей назвали во всех трёх ответах (3 из 3), верхний источник receptionhq.com 67%, ни одного русскоязычного исполнителя. Итог v3 не сведён, факт взят из комментария в черновике страницы U05.

## Evidence walk-through

3 ответа в v2 плюс комментарий по v3. Сводной таблицы по v3 нет.

## Counter-evidence / edge cases

Русскоязычные службы ответа в США могут существовать, просто не попадать в ответы. Внешним исследователям — проверить рынок (auditoriya/russkoyazychnye-ssha).

## Implication for project (подробнее)

Позиция «отвечает за вас по-русски, пока вы один» в ответах ИИ свободна: это кандидат №1 для нашей видимости и страницы Веры (черновик страницы U05 уже написан). Это и аргумент в продаже: сегодня ассистенты русскоязычному владельцу предлагают англоязычных операторов. Выборка крошечная, отсюда уверенность L.
