# Приоритет городов по числу русскоговорящих: Нью-Йорк (234 тыс., из них Бруклин 115 тыс.), Лос-Анджелес (71 тыс.), Чикаго (46 тыс.), Филадельфия, Сакраменто, Майами, Сиэтл (38–41 тыс.), Бостон (32 тыс.); Даллас и Тампа — меньше 9 тыс.

## Context

Агломерации CBSA по языку дома; для выходцев из стран СССР порядок почти тот же, но Чикаго поднимается на второе место (85 тыс.).

## Evidence walk-through

ACS 2024, MOE по агломерациям 4–12 тыс. Порядок первой восьмёрки устойчив, Филадельфия–Сакраменто–Майами–Сиэтл внутри погрешности друг от друга.

## Counter-evidence / edge cases

Майами растёт за счёт новых переездов (2022+), которые ACS 2024 мог учесть не полностью; Telegram-чат Майами почти равен лос-анджелесскому.

## Implication for project (подробнее)

В примерах и кейсах использовать Нью-Йорк, Лос-Анджелес, Майами, Чикаго. Тампа из концепции 23.09 («русскоязычный владелец в Тампе») — малый рынок: 8,5 тыс. русскоговорящих на агломерацию.
