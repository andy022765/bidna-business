# С апреля 2026 цель «максимум квалифицированных лидов» (бывшие Conversion Leads) нельзя выбрать в новой кампании без Conversions API; CRM-интеграция для неё по документации Meta рассчитана на 200+ лидов в месяц, ежедневную загрузку, целевую стадию в пределах 28 дней с конверсией 1–40% и выходит на полный эффект за 3–4 недели

## Context

Справка «About performance goals for lead ads» (782657799338685) и документация «Conversions API for CRM Integration»; извлечено 27.09.2026. Справка свежее: упоминает апрель и август 2026. Документация для разработчиков называет цель Conversion Leads, справка — qualified leads.

## Evidence walk-through

Справка: с апреля 2026 цель «no longer available for new campaign creation without conversions api integration», действующие кампании — с августа 2026. Документация для разработчиков перечисляет условия: 200+ лидов в месяц, загрузка не реже раза в день, целевая стадия в пределах 28 дней, конверсия в неё 1–40%; оценка срока до эффекта — 3–4 недели. H для требований.

## Counter-evidence / edge cases

Документация пишет, что цель совместима только с инстант-формами, справка — что и с формами на сайте (contr-112). Пороги из документации — «guidelines», а не жёсткий запрет интерфейса; на малом объёме цель может быть доступна, но учиться ей не на чем. Цифры −21% и −9,5% — самоотчёт Meta.

## Implication for project (подробнее)

- Инструкция таргетолога §4 и бриф-bidna §9: шаг 4 перенести в «когда будет 200+ лидов в месяц».
- Журнал звонков с отметкой «квалифицирован» ведём с первого теста — он пригодится для своих аудиторий и для этой цели позже.
