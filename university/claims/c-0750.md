# Атрибуция Meta на 2026 год: в стандартной модели click-through — 1 или 7 дней только после клика по ссылке, view-through — 1 день, engage-through — 1 день после прочих кликов и 5 секунд видео; окна 7d_view и 28d_view с 12.01.2026 из API убраны; результаты групп с разными моделями (стандартная, инкрементальная, пользовательская) сравнивать нельзя

## Context

Справка «About attribution models and attribution settings» (460276478298895) и журнал изменений Marketing API за 2025 год; извлечено 27.09.2026. По справке о Commerce Manager (1997130013754737, в очереди) окно по умолчанию для новых групп — 7 дней клик или 1 день просмотр.

## Evidence walk-through

Справка: click-through считает события за 1 или 7 дней «after a link click on your ad»; view-through — 1 день после показа; engage-through — 1 день после прочих кликов, для видео — после 5 секунд просмотра; результаты групп с разными моделями несравнимы. Журнал изменений: с 12.01.2026 окна 7d_view и 28d_view в Insights API не возвращают данных. H.

## Counter-evidence / edge cases

Meta оговаривает, что изменение раскатывается и у части аккаунтов действуют прежние версии click-through и engage-through — у нашего тоже может быть старая. Окно для звонков в справке не описано.

## Implication for project (подробнее)

- Шаблон отчёта (раздел 8 инструкции): добавить строку «Атрибуция: модель · окно».
- Для рекламы со звонком окно — вопрос проверки при сборке, а не догадки.
