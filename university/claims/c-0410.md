# Русскоязычная Америка в Telegram собрана по городам: крупнейшие площадки — городские чаты (Нью-Йорк 21,4 тыс., Майами 18,3 тыс., Лос-Анджелес 17,6 тыс., Чикаго 16,7 тыс.), реклама в них платная через админов; профессиональных сообществ владельцев по ремонту и клинингу заметного размера нет

## Context

Срез публичных счётчиков на 24.09.2026, выборка хэндлов из поиска и перечней; tgstat недоступен. Счётчик ≠ активная аудитория.

## Evidence walk-through

Счётчики — прямое наблюдение, воспроизводимо; вывод «профессиональных сообществ ремонта нет» — отсутствие находки при целевом поиске (поиск site:t.me, перечни). H для чисел, для «нет сообществ» — M, итог H для утверждения о структуре.

## Counter-evidence / edge cases

Закрытые чаты по приглашениям (например, для подрядчиков) поиском не находятся — они могут существовать. Telegram Ads (c-0518) позволяет таргетировать эти каналы без переговоров с админами, но только на привод в Telegram.

## Implication for project (подробнее)

Не строить воронку на одном «бизнес-чате США» (12,7 тыс., коммерческий, смешанная аудитория РФ/США). Искать владельцев через вакансии и через авторов (c-0411). Для Telegram Ads (c-0518) целевые каналы: CHATIK по городам, @USACHATRU, трак-каналы — только если решим тестировать траки.
