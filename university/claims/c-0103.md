# Доказано только, что уже найденный текст можно сделать заметнее в ответе; устойчивого причинного эффекта GEO-работ на то, начнёт ли ИИ органически называть бизнес в нескольких движках, не показано

## Context

Касается всей области GEO на 2023–2026 годы; для местного малого бизнеса доказательств ещё меньше.

## Evidence walk-through

Критический обзор 45 работ: высокая уверенность только для эффекта при уже найденном документе; «белая» GEO устойчиво повышает органическую находимость — низкая; ROI — очень низкая; «+40%» отвергнуто как общее утверждение. Единственный полевой квазиэксперимент с контролем — «наводящий» эффект. H — вывод про отсутствие доказательств прочный.

## Counter-evidence / edge cases

Отсутствие доказательств — не доказательство отсутствия: практики видят успешные случаи; ассоциативные данные (c-0101) говорят, куда направлять работу. Вендорские кейсы «в N раз» не опровергают вывод, потому что не имеют контроля.

## Implication for project (подробнее)

Формулировки: «делаем так, чтобы ИИ было что о вас сказать и откуда взять», «меряем до и после одним протоколом». Не писать «вас будут называть», «после: вас называют». Оставить «мы обещаем, что после нас нейросеть сможет вас назвать» — это обещание о работе. Любой свой кейс оформлять с контролем (c-0109).
