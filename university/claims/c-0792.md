# Meta рекомендует основной текст до 125 знаков и не длиннее 1–3 строк, заголовок до 40 и описание до 25 знаков; длиннее обрезается по месту показа

## Context

Рекомендация справки для большинства плейсментов; отдельные плейсменты и устройства обрезают сильнее.

## Evidence walk-through

Прямая цифра справки. H.

## Counter-evidence / edge cases

Это рекомендация, не правило проверки: длинный текст не отклонят, он просто обрежется.

## Implication for project (подробнее)

Правило инструкции подтверждено; добавить описание — до 25 знаков.
