# Место в списке ИИ и одиночный ответ не являются метрикой видимости; осмысленна только доля ответов с упоминанием по многим запускам и формулировкам, с разбросом

## Context

Справедливо для всех четырёх изученных движков, в API и в приложениях, в местных и брендовых вопросах. Порядок нестабилен сильнее, чем состав.

## Evidence walk-through

SparkToro: одинаковый список реже 1 из 100, порядок около 1 из 1000 (2 961 ответ в приложениях). Schulte: ~65% источников меняются за сутки, бренды стабильнее. Бали: Jaccard повторов 0,22–0,45, через две недели так же. Żatuchin: первое место менялось на 4 из 6 вопросов одинаково в браузере и API. Независимые команды, разные рынки — отсюда H.

## Counter-evidence / edge cases

В тесных категориях (мало кандидатов) верхние бренды появляются почти всегда; там стабильность выше. Это не отменяет вывода про место в списке.

## Implication for project (подробнее)

Смотритель не выводит позицию. Продающие материалы не используют фразы «вы на N месте». Замер нулевой точки и 90-го дня делается одним протоколом, результат — доля с разбросом. Наш лендинг уже так говорит («показываем разброс, а не одно число») — держать.
