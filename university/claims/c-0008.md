# Нулевая точка нашей собственной видимости: в нейтральных вопросах о нашей услуге нас не назвали ни разу — 0 из 95 ответов у людей и 0 из 570 у программы (16–22.09), 0 из 18 по шести замороженным вопросам (23.09)

## Context

Ручной проход (Андрей и Маша: ChatGPT с логином и без, Claude, Perplexity, Google AI Mode) и программа через API (ChatGPT, Claude, Perplexity), три дня. Ранние версии той же цифры — 0 из 74 и 0 из 545 (17.09), 218 ответов (16.09) — это промежуточные срезы той же серии. Отдельно: по прямому запросу с нашим именем Perplexity нас находит, Claude и AI Mode — нет (c-0015).

## Evidence walk-through

Две независимые стороны (люди и API) и повтор через шесть дней. Ноль устойчив. Разметка названий единым правилом (razmetka.py).

## Counter-evidence / edge cases

Похожие упоминания («BI DNA», имена основателей): 3 у людей, 14 у программы. Это не рекомендация, но и не строгий ноль узнаваемости.

## Implication for project (подробнее)

Это можно и нужно говорить публично: «мы меряем себя теми же инструментами, что и клиента, и начинаем с нуля» (разрешено, shtab/pisma.md). Показать рост на своём примере в ближайший месяц нельзя, это работа на квартал. Доказательство по GEO сегодня — честный ноль и протокол, а не кейс. Публиковать ноль вместе с протоколом. Рост показывать только как «назвали или нет» (c-0009).
