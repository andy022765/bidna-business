# Цель 10+ новых клиентов в месяц при рекламном бюджете до $1,000 по бенчмаркам не достигается ни рекламой, ни холодной почтой по отдельности; реалистичная связка — партнёры-посредники + собственный контент и вебинары Андрея и Маши + реклама как ускоритель и ретаргетинг

## Context

Все конверсии «лид → оплата» — допущения 5–15%, собственных данных у нас нет (0 оплат по волне 1, c-0019).

## Evidence walk-through

Сложение коридоров из вендорских бенчмарков — L по определению.

## Counter-evidence / edge cases

Один крупный партнёр (например, бухгалтерская фирма с сотнями русскоязычных клиентов) может дать больше, чем все остальные каналы вместе.

## Implication for project (подробнее)

Отдать Андрею коридор 3–15 в месяц вместо обещания 10+, с контрольной точкой 07.10 (порог 1 концепции США) и через 4 недели.
