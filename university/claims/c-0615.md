# Обещание «вас будет называть ChatGPT» — объективное утверждение о результате, которое по стандарту FTC надо обосновать заранее; при нашей же нестабильности ответов ИИ (совпадение списков 13–30%) обосновать его нечем, поэтому продаётся работа и замер, а не попадание

## Context

Прямого дела FTC о GEO-гарантиях нет; вывод — применение общего стандарта §5 и практики Air AI / DoNotPay / Cox Media Group.

## Evidence walk-through

M: логический вывод из первоисточников плюс наш внутренний замер нестабильности (c-0009).

## Counter-evidence / edge cases

Если накопим собственную статистику «доля клиентов, которых стали называть через N недель», можно будет говорить о типичном результате с раскрытием.

## Implication for project (подробнее)

Для Видимости можно обещать: что мы сделаем (страницы, карточки, упоминания), как измерим (вопросы, движки, частота), и отчёт «было/стало» с честной оговоркой про шум. Нельзя: «вас назовёт ChatGPT», «попадёте в ответы за N дней». Описание замера должно быть буквально верным (API с городом, не приложение; Gemini не меряем).
