# Реклама со звонком в целях Traffic, Engagement, Leads и Sales учится на звонках 60+ секунд (в API — optimization_goal QUALITY_CALL); оптимизации на звонки 20+ секунд нет, а в США 20-секундный звонок — только метрика по умолчанию в колонке «Результаты» при цели «максимум звонков»

## Context

Справка Meta (604687010451937 и 4107704079279896) и руководство Marketing API v25.0 по рекламе со звонком, всё извлечено 27.09.2026. Касается формата call ad — кнопка «Позвонить» в самом объявлении. У call add-on правило другое: лиды и звонки 15+ секунд (c-0744). Meta меняет интерфейс и цели каждые несколько месяцев, поэтому перед каждой новой кампанией правило сверяется в справке.

## Evidence walk-through

Обе статьи справки одинаково пишут, что в целях Traffic, Engagement, Leads и Sales объявление «optimizes for 60-second calls», а в Awareness — на выбранную цель эффективности. В API группа создаётся с optimization_goal=QUALITY_CALL и destination_type=PHONE_CALL. Статья о метриках: при цели «максимум звонков» и аудитории только в США колонка Results по умолчанию показывает звонки 20+ секунд. Три документа Meta согласованы между собой, поэтому H.

## Counter-evidence / edge cases

Обзорная статья 378168646496279 формулирует расплывчато — реклама со звонком «оптимизируется на звонки»; это описание формата, а не цели. При цели Leads кампания идёт через Advantage+ campaign setup, и интерфейс может показать другие варианты цели эффективности — проверить при сборке. Как Meta меряет 60 секунд, не раскрыто (c-0741). Сколько звонков 60+ нужно для обучения, решает лист algoritm-i-obuchenie; на $15–20 в день их будут единицы.

## Implication for project (подробнее)

- В плане и отчёте писать: «оптимизация — звонки 60+ с (Meta); решение — по звонкам 20+ с и 60+ с».
- Правило «победитель — не меньше трёх звонков 20+ с» оставить, но добавить строку 60+.
- Если звонков 20+ много, а 60+ почти нет, люди кладут трубку после приветствия Веры: править первую фразу демо и обещание в объявлении, а не бюджет.
- Ожидания по цене лида — c-0517.
