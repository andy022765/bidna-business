# Замер Видимости через официальные API стоит около $0.17 за вопрос по пяти поверхностям (ChatGPT с поиском, Claude с поиском, Perplexity, AI Overviews, AI Mode), то есть $7–15 на клиента в месяц при 20 вопросах 2–4 раза в месяц и до $67 при 30 вопросах еженедельно с тройным повтором — 1–13% от $500 в месяц

## Context

Вызов ChatGPT с поиском оценён по прайсу в $0.08 (память 15.09 — $0.027, фактический счёт проверить).

## Evidence walk-through

M: цены H, объём вызовов и токенов — допущения.

## Counter-evidence / edge cases

Если поиск делает несколько запросов на вопрос, стоимость Claude и OpenAI растёт.

## Implication for project (подробнее)

Уточняет c-0024 ($6–12): при частом замере с повторами (нужен из-за шума, c-0009) себестоимость до ~$67, но всё равно мала. Себестоимость Видимости — наш труд; цена $1 500 за квартал покрывает API с запасом при любом режиме.
