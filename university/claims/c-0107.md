# Честный замер требует около 7 и более запусков на вопрос, разнесённых по дням, 3–5 формулировок одного намерения, учёта ответов без веб-поиска и интервала, посчитанного по вопросам

## Context

Числа повторов выведены на немецкоязычных и брендовых вопросах; для местных вопросов с поиском список короче и насыщается быстрее (8 организаций).

## Evidence walk-through

Schulte: SE < 0,10 при ~7 запусках; Żatuchin: с поиском набор закрывается к 10–15 запускам, один запуск видит 62–77%; обзор 2026: 3–5 перефразов, ответы без поиска — исход; SparkToro: разные живые формулировки дают один набор брендов при одном намерении. M: стандарта нет, обзор советует подбирать число повторов по пилоту.

## Counter-evidence / edge cases

Для грубого да/нет на крайних случаях хватает меньшего числа; но «хотя бы раз» чувствительно к числу повторов (c-0115).

## Implication for project (подробнее)

Сейчас на лендинге «три движка по три прогона». Предложение: поднять до 7 на движок при той же цене (стоимость API копеечная), оставить «со скриншотами» только как иллюстрацию. Смена числа прогонов между замерами — разрыв базовой линии, помечать.
