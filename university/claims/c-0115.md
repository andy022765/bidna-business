# Критерий гарантии «назвали хотя бы в одном из 27–45 ответов» шумный: три повтора видят лишь 62–77% устойчивого набора, а движки без поиска добавляют редкие имена, поэтому одно упоминание слабо говорит о видимости в обе стороны

## Context

Относится к действующей гарантии лендинга /visibility/ (contr-002 о её юридическом статусе).

## Evidence walk-through

Żatuchin: один запуск видит 62–77% набора пяти запусков; без поиска репертуар не закрывается к 15-му запуску. Schulte: ~7 запусков для SE < 0,10. SparkToro: списки почти не повторяются. Бали: 85,6% никогда не названы — базовая вероятность нуля высока. M.

## Counter-evidence / edge cases

Если бизнес реально стал видим (доля 20%+), 27–45 ответов почти наверняка поймают упоминание — для сильного эффекта критерий работает.

## Implication for project (подробнее)

Вопрос к Андрею, не правка в одиночку. Для любой формулировки — считать только ответы с поиском и с городом, фиксировать движки и число повторов письменно.
