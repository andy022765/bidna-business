# Бот в Telegram Business не может написать первым и отвечает только в чатах со входящим сообщением за последние 24 часа — поэтому дожим «остывших» в Telegram невозможен, рабочая схема «письмо будит, Telegram дожимает»

## Context

Ограничение BusinessBotRights.can_reply нашёл ГОЛОС, ШТАБ перепроверил по документации Telegram 15.09. Решение Андрея 15.09: принято. Правила Telegram п. 5.4 требуют согласия до передачи переписки в Anthropic (SPEC §0).

## Evidence walk-through

Документация Telegram Bot API, проверена дважды. Этап 0 Доводчика собран и выложен выключенным (флаг DOGON_V_PISME), живых переписок не было.

## Counter-evidence / edge cases

Правила Telegram меняются (Bot API 10.0 от 08.05.2026 упоминается в SPEC). Перепроверять перед запуском.

## Implication for project (подробнее)

Доводчик в Telegram — помощник внутри живого разговора, а не автономный дожим. Первое касание остывшего — только письмом, через Resend. SMS-дожим запрещён нашими же условиями /sms (contr-006). Побочный плюс: риск TCPA «пишем первым без согласия» в Telegram физически снят. Продавать надо так: «ведёт переписку, как только человек ответил», а не «догоняет всех». В комплекте Веры описывать Доводчика как email плюс Telegram после ответа человека. Единица учёта — не минуты.
