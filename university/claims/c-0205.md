# Владельцы считают ИИ-поиск важным, но не знают, с чего начать, а 40% проверявших нашли о себе неправду

## Context

Единственный найденный опрос владельцев малого бизнеса про видимость в ИИ с описанной выборкой. Выборка смешанная (Северная Америка, Великобритания, Австралия), вендорская (Squarespace в партнёрстве с Peec AI), самоотчёт.

## Evidence walk-through

Больше 4 из 10 — «очень/крайне важно сейчас», ~2/3 — в будущем; почти 6 из 10 «не знаю, с чего начать»; больше половины не оптимизированы; 34% не пользовались ИИ для маркетинга; ~половина не доверяет ИИ представлять их; 40% проверявших нашли неверные сведения. Одна вендорская выборка — M.

## Counter-evidence / edge cases

Русскоязычные владельцы в США могут отличаться: по внутреннему опыту у 28 из 31 контакта только Instagram, сайтов нет (память Смотрителя) — для них «не знаю, с чего начать» ещё сильнее, а замер покажет ноль. Опрос не говорит, сколько владельцы готовы платить.

## Implication for project (подробнее)

1. Возражение «мне это не нужно» будет редким; частое — «не понимаю, что вы будете делать» → состав работ в оффере по пунктам.
2. Вход через «правду о вас» (где ИИ врёт) подтверждается и опросом, и внутренним направлением `shtab/issledovanie/CHTO-PRODAYOM.md` п. 5.
3. Для контактов без сайта — сначала место, откуда ИИ может взять факты (это работа, а не замер).
