# Для видеорекламы Meta рекомендует главное и бренд в первые 3 секунды, длину 6–15 секунд (истории — до 10), расчёт на просмотр без звука с субтитрами, форматы 9:16 и 1:1 с текстом в центре для Reels и Stories, а для теста — не больше 10 креативов на группу и не меньше 4 дней

## Context

Справка о видео в Instagram; упоминает изменения «конца 2024».

## Evidence walk-through

Рекомендации платформы с её собственными метриками без методики (половина показов — видео, 98% держат телефон вертикально, 2,25× CTR со звуком). Поэтому M.

## Counter-evidence / edge cases

Для отдельных целей Meta допускает видео до 60 секунд. Для рекламы со звонком прямых рекомендаций по длине нет.

## Implication for project (подробнее)

В раздел 3 инструкции («Тексты»): хронометраж, субтитры, первые 3 секунды, текст в центре.
