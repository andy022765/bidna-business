# Рекламный бюджет $1,000 в месяц на Meta даёт ориентировочно 6–36 лидов: средний лид малого бизнеса США стоит около $27 (WordStream 2026), B2B-лид — $138–166 (Metadata 2025); прямого бенчмарка для рекламы на русскоязычных владельцев в США нет

## Context

WordStream — малый бизнес, рекламирующий себя потребителям (нижняя граница); Metadata — B2B-компании, в основном SaaS (верхняя граница). Русскоязычная аудитория в США узкая, CPM может быть выше.

## Evidence walk-through

Два вендорских набора с разными аудиториями — коридор, а не прогноз; L.

## Counter-evidence / edge cases

Узкая этническая аудитория иногда дешевле (меньше конкуренция рекламодателей на русском языке в США) — проверяется тестом. Размер аудитории по языковому таргету видит только Андрей в Ads Manager.

## Implication for project (подробнее)

Бюджет $1,000 в месяц распределять: ~60% Meta (ретаргетинг + вебинар), ~25% Telegram Ads (привод в канал), ~15% резерв на тесты; YouTube-рекламу покупать только после решения, считается ли она «Google Ads» (покупается через него).
