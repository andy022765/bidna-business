# Условия ElevenLabs запрещают передавать защищённые медицинские данные (PHI) без подписанного BAA, BAA доступен только на Enterprise с Zero Retention, а Resend BAA не подписывает — Веру нельзя ставить в клиники, подпадающие под HIPAA

## Context

Разбор 17.09 с дословной цитатой условий ElevenLabs. Там же: имя, телефон и время визита — уже PHI (дело MMG Fusion, март 2026). В цепочке Веры полная расшифровка идёт в письмо через Resend.

## Evidence walk-through

Цитата условий снята 17.09. Остальное — наш анализ, юристом не проверен.

## Counter-evidence / edge cases

Условия и тарифы вендоров меняются. Возможны HIPAA-совместимые альтернативы стека.

## Implication for project (подробнее)

Стоматология и медицина со страховками для Веры закрыты, пока вся цепочка не под BAA (ElevenLabs Enterprise, замена Resend, Netlify Blobs, без Telegram). Возможная дверь — self-pay практики, которые по закону не являются covered entity, но это требует решения Андрея и юридической проверки (contr-009). В нишах для Веры клиники со страховками исключить.
