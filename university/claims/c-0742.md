# Реклама со звонком показывается только на мобильных устройствах — в лентах Facebook и Instagram, сторис Instagram, Reels и Marketplace Facebook (про сторис Facebook статьи Meta расходятся); аудитория — только 18+, номер — из той же страны, что аудитория: мобильный, стационарный или 1-800

## Context

Справка о целях и плейсментах (4107704079279896), обзор (378168646496279) и руководство Marketing API (раздел Limitations), извлечено 27.09.2026. С марта 2026 плейсмент Facebook Feed включает вкладку Friends.

## Evidence walk-through

Обе статьи справки ограничивают показ мобильными устройствами и перечисляют плейсменты; списки совпадают, кроме Facebook Stories (есть только в 4107704079279896). В разделе Limitations руководства API два ограничения: аудитория от 18 лет и номер из той же страны, что аудитория. Обзор разрешает мобильный, стационарный и бесплатный 1-800 номер. H для ограничений; про сторис Facebook — открыто.

## Counter-evidence / edge cases

Advantage+ placements можно оставить включёнными, но показы всё равно пойдут только в перечисленные места. Как ведёт себя кнопка на планшете, справка не говорит.

## Implication for project (подробнее)

- ТЗ на креативы (раздел 6 инструкции): форматы 9:16 и 4:5, обложка читается без звука.
- В чек-лист перед «включай»: аудитория 18+, номер США, плейсменты — мобильные.
