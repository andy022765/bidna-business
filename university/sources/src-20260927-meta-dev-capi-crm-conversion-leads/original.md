## Пересказ по разделам

- Conversions API для CRM — отдельная интеграция, не то же самое, что обычный CAPI для веб-трафика: параметры другие, а данные идут из CRM, а не с сайта. Нужна, если бизнес генерирует лиды в Facebook/Instagram и хочет довести их до продажи через свою CRM.
- Цель оптимизации Conversion Leads на момент документа совместима только с Lead Ads (Instant Forms) — мгновенными формами Facebook/Instagram.
- Критерии «хорошего кандидата» для интеграции: реклама с инстант-формами; желательно хранить в CRM 15–17-значный Meta Lead ID и передавать его с каждым событием (иначе — click ID, телефон или email); не менее 200 лидов в месяц; возможность выгружать данные не реже раза в день; целевая стадия воронки, под которую оптимизируют, наступает в пределах 28 дней после получения лида; конверсия в эту стадию — от 1% до 40%.
- Ориентировочный срок до полного эффекта — около месяца по историческим данным Meta, фактически может отличаться у разных рекламодателей и зависит от ресурсов на стороне рекламодателя.
- Этапы проекта: (1) подключить выгрузку лидов из Meta в CRM — предпосылка, делает рекламодатель; (2) выбрать/создать Meta Pixel для событий CRM — меньше дня; (3) реализовать интеграцию через Conversions API — через партнёра меньше дня, вручную — 3–4 недели; (4) проверка данных Meta — 1–2 дня, без действий рекламодателя; (5) настроить события воронки продаж в CRM — меньше дня; (6) фаза обучения — 2–4 недели, без действий рекламодателя (кампании можно запускать уже во время обучения, но без полного эффекта). Итоговая оценка — около 3–4 недель; время шага реализации можно сократить партнёрской интеграцией (пример — Zapier).
- Роли в проекте: отдел маркетинга и продаж (запускает проект, знает воронку, имеет права в Ads Manager и Events Manager, строит партнёрскую интеграцию); администратор CRM (знает поля и возможности CRM, поддерживает интеграцию); разработчик (строит и поддерживает интеграцию вручную).
