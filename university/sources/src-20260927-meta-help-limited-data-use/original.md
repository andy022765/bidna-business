## Пересказ по разделам

- LDU — опция обработки данных для соответствия законам штатов о приватности; включается флагом при передаче данных.
- С флагом Meta выступает как service provider/processor для помеченных данных жителей штатов, где LDU доступен, и ограничивает их использование по State-Specific Terms.
- Когда слать — решает рекламодатель со своим юристом; пример — клиент отказался от продажи или передачи данных; также — сигнал Global Privacy Control от жителей Калифорнии или Колорадо. LDU появился в 2020 году после вступления в силу CCPA.
- Где доступен флаг: пиксель, Conversions API, App Events API, SDK, Offline Conversions API — для 14 штатов: CA, CO, CT, DE, FL, MD, MN, MT, NE, NH, NJ, OR, RI, TX; Audience Network SDK — те же штаты; списки клиентов — только Калифорния.
- Последствия: возможно падение эффективности, ограничены ретаргетинг и измерение.
- Исключающие аудитории флага не требуют; списки клиентов — флаг только для Калифорнии, аудитория может сократиться.
- Как слать: массив data processing options (подробности — в документации для разработчиков); если не указать штат, Meta определит его сама.
