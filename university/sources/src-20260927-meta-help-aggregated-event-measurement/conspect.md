## TL;DR

Aggregated Event Measurement сегодня. Для веб-кампаний сняты старые требования: не нужно ранжировать 8 событий на домен, вкладка AEM удалена, верификация домена ради настройки событий не нужна, домен конверсии в кампании не выбирается. Оговорка: события CAPI тоже могут обрабатываться в пределах ограничений AEM. Остальное — про app-кампании.

## Thesis

Ручная настройка AEM для сайта больше не нужна.

## Key points

- Нет лимита 8 событий и value sets.
- Нет вкладки AEM.
- Нет обязательной верификации домена для событий.
- Нет выбора домена конверсии.
- События CAPI могут подпадать под ограничения AEM.
