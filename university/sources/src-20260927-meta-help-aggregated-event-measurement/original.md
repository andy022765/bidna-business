## Пересказ по разделам

- С 09.10.2024 отчёты AEM передаются партнёрам мобильных измерений (MMP) с защитой приватности (удаление идентификаторов, дифференциальная приватность, агрегирование).
- AEM — протокол измерения веб- и app-событий пользователей iOS 14+; изменения вводятся постепенно.
- Веб-кампании: не нужно ранжировать 8 событий на домен и включать value sets; вкладка AEM в Events Manager удалена; верификация домена для настройки событий не требуется (может понадобиться по другим причинам); домен конверсии при создании кампании не выбирается. Действий не требуется.
- AEM для кампаний с назначением «мобильное приложение»: Sales (с каталогом и без), Leads, Engagement; не поддерживает оптимизацию на собственные события.
- App-кампании: AEM охватывает App Promotion; почти реальное время отчётов; окна 1 и 7 дней клик; доставка в Audience Network — для кампаний с оптимизацией на app-события и ценность.
- Оговорка: события, отправленные через Conversions API, тоже могут обрабатываться в пределах ограничений AEM.
