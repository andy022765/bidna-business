## Пересказ по разделам

- Число активных объявлений в аккаунте или на странице влияет на предсказуемость результатов: каждый показ учит систему доставки, кому и где показывать объявление лучше всего; чем чаще показывается объявление, тем лучше система оптимизирует его результат.
- Если рекламодатель одновременно ведёт слишком много объявлений, каждое показывается реже — меньше объявлений успевает выйти из фазы обучения, и больше бюджета тратится до того, как система сможет оптимизировать; итог может быть хуже.
- Рекомендация — следить за активным объёмом объявлений и не превышать лимит объявлений на странице (работающих или на проверке); тестировать новые креативы по-прежнему важно, но с оглядкой на этот баланс.
- С июня 2024 года dynamic creative недоступен при создании новых групп с целью Sales или App promotion (старые кампании с dynamic creative не затронуты); вместо неё рекомендован flexible ad format.
- Лучшие практики по снижению объёма: (1) объединять группы — по аудитории (смотреть через разбивки в отчётах), по мелким географиям (в более крупную область, чтобы сложить конверсии и обучение), по плейсментам (через Meta Advantage+ placements, бывшие automatic placements, с подбором ассетов под плейсмент), по языкам (несколько языков в одной группе; для каталогов — фид с языком и/или страной); (2) уменьшать число объявлений в группе, сохраняя разнообразие креативов — одно объявление может нести до 10 креативных ассетов; для вариантов текста — multiple text optimization, для вариантов креатива — dynamic creative, для вариантов формата — Advantage+ creative for catalog; (3) использовать отраслевые решения, которые кроют весь ассортимент меньшим числом объявлений: локальные фичи для сетей магазинов, Advantage+ catalog ads для товаров, real estate ads (после объединения групп) для недвижимости, automotive inventory ads для автомобилей.

> "fewer ads exit the learning phase, and more budget is spent before the delivery system can optimize performance."

> "combining ad sets will help you get the conversions you need to exit learning phase sooner."
