## TL;DR

Определения метрик рекламы со звонком и путь к колонкам в Ads Manager. Calls placed — начатые из объявления звонки; 20/60-second calls — соединения не короче 20/60 секунд; callback requests submitted — просьбы перезвонить. Метрики частично смоделированы. В США при цели «максимум звонков» колонка «Результаты» по умолчанию показывает звонки 20+ секунд. Статья 237108475737601 из брифа.

## Thesis

Meta показывает звонки как частично смоделированную оценку, а в США «результат» рекламы со звонком по умолчанию — звонок 20+ секунд.

## Key points

- Метрики: estimated call confirmation clicks, calls placed, 20-/60-second calls, callback requests submitted.
- Путь: Columns → Customize columns → Engagement → Calling.
- Частичное моделирование вместо прямого счёта.
- Нет метрик для кампаний до 20.06.2025 вне шести стран.
- США + «maximize number of calls» → колонка Results = 20-second calls.
