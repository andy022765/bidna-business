## Пересказ по разделам

- Метрики рекламы со звонком: оценка нажатий подтверждения вызова, calls placed, 20- и 60-секундные звонки, просьбы перезвонить; доступны глобально, видны в Call insights.
- Метрики частично получены моделированием — полезно там, где данных не хватает.
- Определения: calls placed — сколько раз из объявления позвонили в бизнес; 20-/60-second calls — сколько звонков закончились успешным соединением не короче 20/60 секунд; callback requests submitted — сколько людей через кнопку сообщения попросили перезвонить.
- Для кампаний, созданных до 20.06.2025 вне США, Австралии, Бразилии, Канады, Мексики и Израиля, метрик нет.
- Как включить: Ads Manager → Campaigns → Columns: Performance → Customize columns → Engagement → Calling → отметить метрики → Apply.
- Примечание: при цели эффективности «maximize number of calls» и аудитории только в США метрика 20-секундных звонков становится метрикой по умолчанию в колонке Results.
