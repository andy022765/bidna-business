## Пересказ по разделам

- Советы по тексту в рекламе; с 6 мая 2024 года на функции текста распространяются дополнительные условия использования генеративного ИИ Meta (генерация и улучшение текста, генерация фона, расширение изображения).
- Функции: image template (баннер с настраиваемым цветом/шрифтом текста); text overlay (ИИ накладывает варианты текста на креатив); text generation (ИИ создаёт до 5 вариаций основного текста и заголовка); placement asset customization (текст подстраивается под конкретный плейсмент); add text options (несколько вариантов текста — система сама подбирает по ML-предпочтениям аудитории).
- Рекомендации: короткий текст (1–3 строки для основного текста); сразу сообщать, что сделать зрителю, — для этого доступен набор кнопок CTA под разные бизнес-цели.
- Длина: рекомендовано 125/40/25 знаков (основной текст/заголовок/описание) для большинства плейсментов; на части плейсментов и устройств обрезает сильнее.
- Пустой текст на креативе может автоматически подтянуться с сайта-назначения и стать нередактируемым; текст объявления из существующего поста страницы тоже нельзя редактировать.
- Улучшения Advantage+ creative (например, text improvements) могут скорректировать загруженный текст; часть включена по умолчанию. Настройка аккаунта «тестировать новые оптимизации» применяет тестовые улучшения независимо от выбора на уровне объявления; выключить и то, и другое можно в любой момент.
- Часть отраслей (финансы, фарма и здоровье, категории HEC, соцвопросы/политика) и стран может не получить доступ к генеративному ИИ сразу.
