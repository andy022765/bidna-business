## TL;DR

Агентство Seer Interactive (февраль 2025) сопоставило 500+ ссылок из ответов ChatGPT с выдачей Bing и Google по тем же вопросам: 87% совпали с органикой Bing, 56% — с Google. Авторы объясняют расхождения сокращением длинных вопросов в поисковые запросы.

## Thesis

Ссылки ChatGPT-поиска в основном берутся из топа Bing.

## Key points

- 87%+ ссылок совпали с органикой Bing (в основном топ-10, часть 11–20); с Google 56%, медианная позиция 17.
- Несовпадения — Википедия, агрегаторы, новости.
- ChatGPT, вероятно, упрощает длинный вопрос до короткого запроса.
- По их данным, поиск включался примерно в 30% вопросов (Semrush: 46%).

## Methods / evidence

Точное сопоставление вопрос → запрос и ссылка → URL; интерфейс ChatGPT; SeerSignals для выдачи.
