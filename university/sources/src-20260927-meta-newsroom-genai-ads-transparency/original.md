## Пересказ по разделам

- «AI info» — на рекламу, созданную/существенно изменённую генеративными инструментами Meta; в меню «…» либо у «Sponsored» (фотореалистичный ИИ-человек в кадре → сразу у «Sponsored»); без существенной правки и без такого человека метки нет.
- С обновления Meta сама распознаёт по «отраслевым сигналам» рекламу из сторонних ИИ-инструментов и тоже ставит «AI info».
- Область — изображения и видео; нет требования самораскрытия ИИ для обычных рекламодателей, нет упоминания голоса, водяных знаков или C2PA/IPTC.
- Для сверки — справка meta.com (не отдельный источник): мелкая правка (ресайз, цветокоррекция) метки не даёт; для соцвопросов/выборов/политики раскрытие ИИ (включая аудио) уже обязательно, но только там.

## Короткие цитаты для сверки (дословно)
