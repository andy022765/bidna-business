## Пересказ по разделам

- CAPI — прямая связь маркетинговых данных (с сервера, платформы сайта, приложения или CRM) с системами оптимизации Meta: веб-, app-, офлайн- и события переписки.
- Офлайн-конверсии используются для оптимизации в кампании с целью Sales при выборе «сайт и магазин».
- Один API для событий из разных источников: сайт, магазин, почта, чаты, телефон, приложение, офлайн. Можно заменить им App Events API и Offline Conversions API.
- Примечание: Offline Conversions API прекращает работу в мае 2025; события переводятся в наборы данных через Conversions API.
- Польза для веб-событий (по словам Meta): меньше потерь из-за ошибок браузера, связи и блокировщиков; оптимизация на поздние действия; лучше измерение; больше совпадений событий и выше event match quality.
- Веб-события CAPI связаны с пикселем: та же оптимизация (максимум конверсий и ценности), те же отчёты, те же ограничения условий Business Tools; CAPI не предназначен для обхода правил вроде ATT или ePrivacy. Рекомендуется использовать вместе с пикселем.
- App-события через CAPI — меньше зависимости от SDK; офлайн-события — измерение продаж в точках, аудитории и lookalike, lift-исследования; события переписки — оптимизация клик-в-Messenger на покупки.
