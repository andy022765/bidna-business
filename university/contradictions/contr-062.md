# Contradiction: Twilio «подпишет BAA на отдельных условиях» против «только на Security или Enterprise Edition»

## Position A

KLINIKI-I-HIPAA.md (17.09), таблица цепочки: Twilio — «да, на отдельных условиях».

## Position B

Страница Twilio HIPAA (c-0614): BAA только для клиентов на Security Edition или Enterprise Edition.

## Why they conflict

Уточнение: «отдельные условия» — это платная редакция аккаунта. Наш аккаунт Twilio общий на всех клиентов; переход на Security Edition меняет стоимость для всех.

## What would resolve it

Цена Security Edition у Twilio.

## Current working assumption

Клиникам со страховыми заявками ничего не обещаем до расчёта цепочки.
