# Демо-данные №44 CareLine — Brightside Home Care (DEMO)

Всё вымышленное и помечено DEMO. Неделя расписания и визитов — понедельник 05.10 – воскресенье 11.10.2026, Бруклин и Квинс, пояс America/New_York.

Собирает `generator.js` с фиксированным seed 44:

- `node generator.js` — пересобрать все файлы;
- `node generator.js --proverit` — сверить файлы на диске с тем, что даёт seed (то же проверяет `platforma/test/evv.test.js`).

Генератор сам прогоняет движок EVV: на чистой выгрузке должно быть 0 исключений, на грязной — ровно список из `oshibki-ozhidaemye.json`. Не сходится — генератор падает и файлы не пишет.

## Что вымышлено и как помечено

- Имена сиделок — «имя + инициал» (Rosa M.) из общих списков; у клиентов имён нет вовсе, только код.
- Телефоны — только вымышленный диапазон NANP 555-0100…0199: сиделки +1 347 555-01xx, клиенты +1 718 555-01xx.
- Адреса — «DEMO address, Brooklyn, NY 11235»; координаты — точка ZIP переписи 2020 со сдвигом до ~450 м.
- Номера Medicaid — `DEMO-00001…`; налоговый номер агентства — `000000000`; плательщик — `DEMO-MLTC-01` / «DEMO MLTC Plan».
- У каждой записи JSON `"demo": true`; в каждой строке CSV в колонке Notes есть DEMO.

## Колонки выгрузки EVV

Имена колонок взяты из публичного макета импорта визитов HHAeXchange «Homecare V5 Flat File Import Layout» (подмножество из 96 полей, формат времени `YYYY-MM-DD HH:MM`) плюс колонка `Visit Date`, как в выгрузках портала. Настоящий экспорт из портала агентства может называть колонки иначе: нормализатор `vizityIzCsv` в `platforma/lib/care/evv.js` узнаёт синонимы (Patient ID, Admission ID, Call In Time, Service Code и другие, список — `KOLONKI`), понимает `MM/DD/YYYY`, AM/PM, «;» и табуляцию. Точные имена колонок у конкретного агентства надо сверить на его файле.

| Колонка | Поле визита | Смысл | Где используется |
|---|---|---|---|
| Visit ID | `vizit_id` | номер визита | во всех исключениях |

## Нормальное, на что движок не должен срабатывать

- 2 пропущенных визита (Missed Visit = Y) и 1 удалённый дубль (Is Deletion = Y).
- 3 ручные правки с кодом причины: уход внесён вручную, приход внесён вручную, время прихода исправлено.
- 2 ухода у поликлиники с типом места Community (сопровождение клиента) — GPS в 1,5 км от дома, это не ошибка.
- 8 клиентов отмечаются звонком с городского телефона, 2 — FOB, остальные — приложением с GPS.
- Отметки гуляют от −5 до +6 минут вокруг расписания; единицы к оплате — целые 15-минутные по реальному времени.

## Ограничения

- Расстояние между ZIP — по прямой между точками переписи, не маршрут на транспорте (источник и точность — в `platforma/lib/care/zip.js`).
- Радиус «визит дома» 400 м, недельная авторизация с понедельника и округление NY до целых 15-минутных единиц — допущения; что подтверждено источниками, а что нет — `ISTOCHNIKI.md`.
- Данные только для NY. Правила NC проверены отдельными тестами на коротких выгрузках.
