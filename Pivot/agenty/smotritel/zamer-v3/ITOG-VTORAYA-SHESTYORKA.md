# Вторая шестёрка — результат. Как спросили, то и ответили

**Снято 23.09, размечено 24.09.** Два набора по шесть вопросов, по 30 ответов каждый,
три нейросети, режим принудительного поиска. Ошибок и неполных ответов — ноль.

- **Первая шестёрка** (`zamer-v2`, заморожена 23.09): вопрос «что делать», без географии.
- **Вторая шестёрка** (`zamer-v3`): тот же покупатель и те же шесть положений,
  но форма «кто может» и слова «в США».

## Главное: нас по-прежнему не называют

**0 из 30 и 0 из 30.** Ни в одном наборе, ни одной нейросетью. Нулевая точка стоит.

## Второе главное: форма вопроса решает почти всё

Доля ответов, где нейросеть вообще назвала хоть одного исполнителя:

| Набор | Назвали хоть кого-то |
|---|---|
| «что делать», без географии | **7 из 18 (39%)** |
| «кто может», с «в США» | **15 из 18 (83%)** |
| | **+44 пункта** |

По вопросам видно ещё резче. Там, где человек спрашивает «что с этим делают», нейросеть
читает вопрос как просьбу о совете: G01 — 0 из 3, ответ про режим «Не беспокоить» на айфоне.
Там, где он спрашивает «кто может» — U01 и U04 дают 3 из 3.

| | «что делать» | | «кто может» | |
|---|---|---|---|---|
| не успеваю отвечать | G01 | **0 из 3** | U01 | **3 из 3** |
| половина не дозванивается | G02 | 1 из 3 | U02 | 2 из 3 |
| вечер и выходные | G03 | 1 из 3 | U03 | 2 из 3 |
| сколько теряю на пропущенных | G04 | 1 из 3 | U04 | **3 из 3** |
| отвечать по-русски | G05 | 3 из 3 | U05 | 2 из 3 |
| человек или робот | G06 | 1 из 3 | U06 | **3 из 3** |

**Оговорка, без которой цифра врёт.** Во второй шестёрке изменены сразу две вещи: форма
вопроса и география. Что именно сработало — по этим данным не разделить. Косвенно в пользу
формы говорит G05: он был единственным в первой шестёрке, где уже стояло «в США», и уже там
дал 3 из 3, тогда как соседи по набору давали 0–1.

## Что из этого следует для работы

1. **Страницы пишем под форму «кто может».** Там, где нейросеть даёт совет, попасть в ответ
   можно только как источник совета — это другая, гораздо более трудная цель.
2. **Кто занимает места, которые мы хотим.** На второй шестёрке верхние источники —
   ruby.com (100% на U01), nextiva.com, posh.com, patlive.com, smith.ai, answerconnect.com,
   answering365.com. Это службы ответа и телефония, почти все — с живыми операторами
   и по-английски. Русскоязычных нет ни одного.
3. **Это же — материал для продукта.** Клиенту на своём примере показываем: формулировка
   вопроса меняет ответ сильнее, чем всё, что он успеет сделать за квартал. Поэтому список
   запросов мы замораживаем письменно до начала работы, а не подбираем задним числом.
