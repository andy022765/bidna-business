# СКВОЗНАЯ НАХОДКА: выдуманная опора — это система, а не случай

$85 016 был не единичной ошибкой. В четырёх восстановленных письмах **четыре**
утверждения одного типа — ссылка на несуществующее доказательство:

| Письмо | Фраза | Чем обеспечено |
|---|---|---|
| Семенова | «По нашей статистике, это критически важно для повышения конверсии» | своей статистики нет |
| Семенова | «продано на $85 016 больше за два месяца» | панель Влада; «больше» и «благодаря» не доказаны |
| Луркова | «По статистике они теряются по пути и больше не возвращаются» | источник не назван |
| Анжелика | «Все те, с кем мы уже поработали, сходятся в одном мнении» | подтверждённый кейс один |
| Анжелика | «С этими задачами мы нынче справляемся очень успешно» (франшизы) | франшиз не было |

Общий механизм: там, где нужен довод, подставляется авторитет, которого нет.
Ни одно из этих мест не проверяется получателем сразу — но каждое взрывается на звонке,
когда человек спросит «а покажите».

**Что с этим делать — решение Андрея.** Вариант, который я предлагаю: перед отправкой
письма проверять одно — **под каждым утверждением есть источник, который я могу
показать в ту же минуту**. Если нет источника, утверждение вычёркивается, а не смягчается.

**И организационное.** Пока черновики и отправленное расходятся, мы не знаем, что
обещано людям. Восстановлено 4 письма из 14. Остальные десять — только у Маши.
