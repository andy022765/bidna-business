# Голос: Дежурный «Вера»

Русскоязычный агент на входящие звонки. **Живой: https://dezhurny-r4p8w2.netlify.app**
Полная картина — в авто-памяти `project-golosovoy-dezhurny` и в CLAUDE.md.

## Что где лежит

- `PROMPT-DEZHURNY.md` — **мозги, источник правды.** Общая рамка (закон, длина реплики,
  числа словами, посторонние голоса, анти-гарантия) + три линии: риэлтор · клиника ·
  наш Дежурный. Сверен с облаком знак в знак.
- `sozdat_agenta.py` — заводит и перенастраивает агента у ElevenLabs. Все ручки
  задержки и русские филлеры зашиты тут же, чтобы обновление их не снесло.
- `agenty.json` — id агентов. `instrumenty.json` — id инструментов.
- `zamer_tts.py` · `repliki.json` · `golosa.json` · `audio/` — замерялка голосов.
  Замерен ОДИН голос и тот контрольный английский; шесть русских не слушали.
- `site/` — стенд. `web/` (страница + движок), `netlify-functions/`:
  `golos-url.js` (подписанный адрес + квота), `pismo.js` (письмо через Resend),
  `mesta.js` (живой счётчик мест из купона Stripe).

## Команды

```bash
source ~/.bidna-golos.env

# перенастроить агента после правки промпта
ELEVENLABS_STAND_KEY="$ELEVENLABS_API_KEY" python3 sozdat_agenta.py \
  --liniya dna --golos EXAVITQu4vr4xnSDxMaL --obnovit <agent_id из agenty.json>

# выкатить стенд (из site/)
netlify deploy --prod --dir=web --functions=netlify-functions \
  --skip-functions-cache --site 4583b8b6-f9f4-4fae-b369-d107c8ac56a3
```

**Грабля:** без `node_bundler = "esbuild"` в `netlify.toml` зависимости функций
не попадают в бандл и функция падает на проде с `Cannot find module`.
В основном проекте это записано с датой 03.09 — наступили второй раз 12.09.

## Чего ещё нет

1. **Телефонии.** Сегодня это браузер. Номер надо принести: Twilio native
   (минуты на подключение, warm transfer только там) или SIP/Telnyx (дешевле,
   но перевода на живого нет).
2. **Письма владельцу после звонка.** Вебхука нет, и дедуп в `pismo.js`
   (`день:шаг:почта`) пропустит ему только первое письмо за сутки — чинить до запуска.
3. **Обкатки.** Три звонка за всю историю, пять нарушений промпта. Версия от 12.09
   15:42 не проверена ни одним звонком.
