## ГЛАВНАЯ НАХОДКА ПО МЕТОДУ: PDF у Perplexity теряет ответ

Первый вопрос сохранили в PDF, как велела инструкция. **Получилась одна страница: вопрос,
начало ответа и таблица.** Списка из шести пунктов и заключения нет — потеряно больше половины.
Причина: Perplexity держит ответ в собственном прокручиваемом блоке, печать берёт только видимое.
В PDF оказалось **3 ссылки вместо 15**.

Перешли на **Cmd+S → Webpage, Complete**. В HTML сохраняется всё: полный текст и все источники.
Для сравнения на том же вопросе: PDF — 3 домена, HTML — 14.

**Вывод для СОТРУДНИКОВ: PDF как формат замера непригоден ни для ChatGPT (вчера — теряет
источники), ни для Perplexity (сегодня — теряет сам ответ). HTML сохраняет оба.**
