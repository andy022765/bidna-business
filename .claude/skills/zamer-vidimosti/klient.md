## `voprosy.json` — формат
ID только вида `KR01` / `KE01` (буквы + цифры, без буквы в конце): `V1R` не проходит регулярку трат в progon.py (дыра 1).
Всем вопросам `opornyy: true` (иначе Claude без поиска молча выпадет) и `rukami` (обязательное поле).

## Регулярка клиента
- **Латиница + кириллица + домен(ы):** `worldspeak|ворлд\s*спик|worldspeakschool\.com`. Если русский ответ напишет имя кириллицей, без неё будет ложное «не назван» ровно на русской половине. (Проверено 29.09 на v1: в ответах про WorldSpeak кириллицы не было, имя латиницей — в 90 из 110 ответов; кириллицу всё равно держать.)
- **Без общих слов.** «Remote CFO», «Spanish school» совпадут с чужими ответами → ложное «назван». Брать отличительное слово имени + домен; при нужде — фамилию владельца.
- **Новый сайт** (решение 29.09: «видимость держится на сайте, при нужде новый») — новый домен добавить в регулярку для «после» и записать в отчёт, что регулярка расширена и чем.
- Проверка на «до»: `tablicy.py zamer-k-<клиент> --imya "<regex>" --primery 3` — прочитать куски текста с совпадением, нет ли ложных.

## Отчёт «до» — скелет (`zamer-k-<клиент>/OTCHET-DO.md`)
1. Что меряли: список (дословно), даты, слот, три движка, 7 повторов, отпечаток и хэш, регулярка.
2. Назван ли: X из N сочетаний; таблица «вопрос × язык × движок → устойчиво / мелькание / не назван», **отдельно «в тексте» и «только в источниках»**.
3. Кого называют вместо клиента (по сочетаниям, где назван хоть кто-то; читать тексты — бесплатного инструмента с именами нет).
4. Верхний источник и его доля по каждому вопросу и движку; где есть «хозяин» (> 50%).
5. Доля источников .ru/.by по каждому движку; оговорка: Claude на русских вопросах тянет российские зоны сам по себе.
6. Модель в ответе по каждому движку (`model_v_otvete`; это имена-псевдонимы, смену модели за ними программа не видит).
7. Оговорки: «меряем через программные входы нейросетей; это близко к тому, что видит человек, но не равно ему»; Google AI Mode и AI Overviews программа не меряет; место в программе — Los Angeles.
8. Что дальше: повтор <дата> тем же списком и слотом; условие возврата — ни одного «устойчиво назван» за квартальный замер (PROTOKOL-V2.md).

Нельзя: строку `kriteriy` «УСЛОВИЕ ВОЗВРАТА НАСТУПИЛО» с «до» (это нулевая точка); место в списке, проценты роста, сроки; выводы по одному ответу; в английском тексте суммы, ROI, гарантии. Клиенту — только после слова Андрея.

## Решение о возврате
Условие — ни одного «устойчиво назван» за квартальный замер (PROTOKOL-V2.md; какие замеры входят в «квартальный», сверить там перед первым случаем). Считает скрипт по правилу «назван», утверждённому Андреем (см. «До первой продажи»), решает Андрей. До решения проверить полноту: выпавший движок даёт ложное «УСЛОВИЕ ВОЗВРАТА НАСТУПИЛО» (дыра 4); упавший повтор — добрать, а не считать «не назван» (26.09).
