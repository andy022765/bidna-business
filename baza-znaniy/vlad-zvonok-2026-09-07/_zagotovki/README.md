# Заготовки из умершей сессии 89fc6f76

**`call.js`** — виджет звонка голосовому AI-продавцу («Валюша») прямо из браузера.
Клик → гудки → агент берёт трубку и говорит. WebRTC напрямую в pipecat `/api/offer`,
без внешних SDK. Адрес сервера агента берётся из `?bot=...` в адресе страницы или
из `window.VALYUSHA_BOT_URL`.

Это готовое **живое демо для блока «AI-продавец»** в статье-кейсе: человек не читает
про голосового агента, а звонит ему со страницы. Самое сильное доказательство из пяти
инструментов, потому что единственное, что можно потрогать.
Перед публикацией нужен рабочий адрес агента — он у Влада.

**`iframe-test.html`** — стенд, где проверяли встраивание наших сайтов в рамку.
Под блок «AI-сайты»: показать живую страницу прямо в статье, а не скриншот.
